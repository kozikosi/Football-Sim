## 4. Three things to know before this lands

1. **The guide is one shared HTML string**, rendered both in the Guide tab (`guideBody`) and inside the Draft Simulator's guide panel (`draftGuideHost` → `guideHTMLCached()`). Removing the Guide box therefore removes it in **both** places, because there is only one copy of the markup. If the Draft Simulator should keep its box, it needs a parameter — one line. The same is true of the "Play the season" line and the tier list.
2. **The "14-team playoff" detail is gone from that sentence** because the Owner's rewrite says "the playoffs". The sim still runs 14 teams; only the wording changed.
3. **"Linebackers" is a new row in the Unit Comparison** and "Primary Coverage" is gone (that is what makes the count 14 in both versions). If the Owner wants Primary Coverage kept as well, the table becomes 15 rows and the grouping needs one more line.
