## Findings (why "improved", not "ok")

1. **The flex chip count (39 → 44) is state-dependent, and the README reports it as if it were fixed.** Slice 1 REV 2 saw 39 chips; Slice 2 sees 44. The count changes because the board now starts with a CHOSEN team (Chicago Bears) instead of a random team, so the draft state (on-clock team, available slots, pickers probed) differs — and the seed is random per run, so the count varies run to run. The battery correctly asserts the chips are OBSERVED and read "-N flex" (not an exact count), so this is not a test failure. But the README's "44 chips seen" reads like a stable number. **Ask:** Z.ai should note in the README that the chip count is state-dependent (chosen team + random seed) and the law is the observation, not the count.
2. **"The board drafts as the CHOSEN team" is asserted by the header name only.** The battery checks `.cp-team` reads "Chicago Bears" after START. It does not verify that the chosen team is actually on the clock at its picks through the draft, or that the user's picks land on the chosen team's roster (rather than the header label simply displaying the chosen name). The flow code (`START { userTeam: teamIndex }` + the engine's draft logic) makes this likely correct, but the battery does not prove it end-to-end. **Ask:** a deeper check — draft several rounds as a chosen team and confirm the chosen team is on the clock at its slots and its picks land on its roster. Filed as P-315.
3. **The pick-position choice is deliberately NOT in Slice 2 — this is an open Owner decision.** The README notes the seed stays app-controlled/random and "the Owner decides whether Team Select should offer a pick slot." KG should know this is a decision point, not a missing feature. **Ask:** the Owner to decide — should Team Select offer a draft-pick-slot choice (e.g., pick 1st, pick 16th, random), or does the seed stay app-controlled? (No action for Z.ai until the Owner decides.)
4. **The gone-odds tooltip + my-needs sticky row are carried to Slice 3.** Documented in the README and the commit message. Good — they are not lost. **Ask:** Z.ai to build Slice 3 (the board chrome pass, including these two carried innovations) as the next slice.
