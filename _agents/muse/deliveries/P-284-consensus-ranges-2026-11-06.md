## Coverage note (depth keys)

VL, OR, and VLOC did not use the standard 32-slot depth set. They used an 8-key depth set (WR4, DL5, LB4, CB4, SS2, FS2, FB, P) and did not list TE3 or DIME. Their depth values are near-zero (VL: WR4 16, DL5 16, LB4 16, CB4 63, SS2 16, FS2 16, P 3, FB 3; OR: WR4 5, DL5 5, LB4 5, CB4 5, SS2 5, FS2 5, P 1, FB 1; VLOC: WR4 15, DL5 15, LB4 15, CB4 15, SS2 15, FS2 15, FB 10, P 35). Beam, GPT, Groq, and DS used the standard 6 unmeasured slots (WR4, TE3, FB, P, DL5, DIME) at Colors values (10, 10, 30, 100, 145, 40, with Groq WR4 15 and DL5 140). The FB/P/DL5/WR4 ranges above therefore reflect a METHOD split (near-zero depth keys vs Colors values), not a measurement disagreement. The review should settle which depth treatment the final table uses.
