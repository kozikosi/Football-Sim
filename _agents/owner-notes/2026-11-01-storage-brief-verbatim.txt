1. The product and the problem
Browser-based NFL simulator (w58, post-Colors). Draft, single season, playoffs, Super Bowl. It persists nothing today — refresh and you start over. This wave delivers: autosave of drafts, seasons, and per-week game previews; up to 3 parallel save slots; a local profile; global career stats; minimal settings; a copy-paste brag share. No accounts, no sign-in, no backend, no cloud. No file downloads, no export/import screens, no hidden full-save backup — the brag share (text + game URL, no save data) is the only clipboard feature. Storage isolated from the UI and portable to Svelte/React later.

3. Council convergence — requirements
Local-first, no accounts. Isolated async facade (load/save/list/delete/migrate) — screens never touch storage. Invisible autosave; Continue is the primary CTA on load when a save exists. Corner avatar → lightweight expanding panel. Version by save kind (v1:draft, v1:season, v1:week) + in-blob schema + forward-only migrations. Write safety: temp-key swap, one-deep backup, validate on load. Quota/private-mode/corruption handled: catch, prune oldest expendable first, tell the user once, never silently lose a run. Multi-tab storage-event warning. Soft-delete + overwrite confirmation. Materialized-outcome snapshots for v1 (RNG unseeded today). Never serialize the full player DB or play-by-play — deltas only. Aggregated key-player ledger, never append-only. Event-driven saves at committed checkpoints, debounced 500ms–2s, never mid-sim; also on visibilitychange/pagehide. Visual identity protected; reduced motion genuinely disables nonessential animation. Written Phase 0 plan before code.

5. Tensions worth naming
(a) Per-week saves dissolve the mid-game RNG problem — you never resume mid-stream, so unseeded randomness doesn't threaten resume honesty. Confirm the engine can cleanly re-enter at any week's game preview. (b) Corrected: cleared browser data loses everything — the one-deep backup lives in the same storage origin and is wiped with it. The backup protects against failed writes only (killed mid-write, quota error, corrupted blob), not against a data clear. This risk is accepted explicitly. The app must never imply a cleared-data recovery path exists — no empty "restore" option, no "we found a backup" that isn't there. (c) The ID/freeze decision resolves database-versioning cleanly — but only if IDs actually get created and saved seasons pin their snapshots. That's a Claude deliverable. (d) The brag share is a share action, not just selectable text: a button on the results screen copies "I went X-Y and [result] with [team]. Can you go undefeated? [URL]" to the clipboard with a confirmation toast. The link is the deployed game URL — no parameters, no encoded state, no save data; never a local file path or localhost.

8. Edge cases — clarified, not new decisions
* 		A mid-draft state freezes to its starting database when the player DB updates — only drafts started after an update use new data. (Otherwise the board changes under the user mid-draft.)
* 		Per-team global stats = best W-L record, best result (Super Bowl win vs. best playoff run), and total seasons/record with that team.
* 		Global achievements survive slot overwrite as well as deletion.
* 		"Undefeated season" = undefeated regular season (17-0, 16-0, schedule-length-agnostic). The brag may riff ("can you go undefeated?") without defining 20-0.
* 		Profile empty state: "No achievements yet — finish a season to start your legacy." Never a blank panel.
* 		Only completed seasons (through the Super Bowl) record global stats. Abandoned seasons record nothing. Completed drafts that never become seasons record nothing.
* 		Rolling preview is a requirement: only the current week's preview is saved; previous weeks' previews are deleted; the user cannot return to an earlier week's preview.
* 		Playoff-victory audio: optional, only if genuinely free; otherwise out of scope. Do not let it expand the wave.
* 		Run-it-back uses the same player pool (same IDs) with the latest ratings — "same players" means same pool, not a frozen replay.
9. What success looks like
Start a draft → close the browser → return mid-draft. Play a season → refresh mid-week → replay from that week's preview. Finish → achievements recorded globally, overall and by team. Run it back in another slot. Overwrite only with confirmation. Copy a brag ("I went 14-3 and won it all with Carolina. Can you go undefeated? [link]"). No accounts, no downloads, no cloud, no redesign.
