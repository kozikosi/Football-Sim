DS tools-eval — measurements, 2026-11-19
========================================

Machine: Owner's Mac, macOS 15.6, Node v26.13.0, npm 11.x, Vite 8.3.6 (Rolldown build), Svelte 5.57.3,
Vue 3.5.x, TypeScript 5.9.3. Each app is a fresh Vite build of the SAME feature: 32 stat rows, a Season/Playoff
tab pair, a text filter, sortable columns, one expandable row, and an inline SVG sparkline per row.

How measured: after `vite build`, every `dist/assets/*.js` and `*.css` file was piped through `gzip -9`.
"raw" is the sum of the JS bytes; "js_gz" the sum of their gzip -9 bytes; "css_gz" the gzip of the one CSS file.

  $ for app in sv-base sv-base/tanstack vu-base vu-base/tanstack vu-base/prime; do
      js=$(ls dist/assets/*.js); raw=$(wc -c < "$js"); gz=$(gzip -9 -c "$js" | wc -c); ...
    done
