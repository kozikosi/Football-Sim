# Football Sim — Vue 3 + Vite

A standalone Vue 3 + Vite scaffold for evaluating the Vue ecosystem as a potential foundation for Football Sim.

## Stack
- Vue 3
- Vite 8
- TypeScript
- Pinia
- Vitest
- Playwright

## Requirements
Node.js `^22.18.0 || >=24.12.0`.

## Setup
```sh
npm install
npm run dev
