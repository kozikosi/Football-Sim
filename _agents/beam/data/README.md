# Madden NFL 27 Player Ratings Data

## Files
- `parse_madden_ratings.py` — parser (in `_agents/beam/tools/`)
- `madden-ratings-raw.txt` — raw scrape (YOU must save the pasted ratings here)
- `madden-ratings.json` — parsed output (name, pos, team, ovr, spd, str) — generated by the parser

## How to generate
1. Save the raw Madden ratings page text to `_agents/beam/data/madden-ratings-raw.txt`.
2. Run: `python3 _agents/beam/tools/parse_madden_ratings.py _agents/beam/data/madden-ratings-raw.txt _agents/beam/data/madden-ratings.json`
3. Verify player count (~1941) and spot-check a few entries.

## Notes
- Only name, pos, team, ovr, spd, str are kept (no XF/AGI/COD/INJ/AWR).
- Footnote numbers (1-4) are filtered out automatically.
- Parser identifies players by known POS + TEAM tokens.
