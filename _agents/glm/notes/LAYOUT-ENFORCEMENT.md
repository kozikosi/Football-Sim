## 2. The case every mechanism must catch

**`Sim/` ↔ `sims/`.** A session interested in `sims/` (the planned per-sim destination) types `Sim/foo.html`. The write tool auto-creates `Sim/`, the file lands in the empty duplicate, nothing fails, and the record now has a seventh topology. This is a path-typo case, not a navigation case: the session never opens `Sim/`, never reads a README there, never browses docs. Any mechanism that depends on the session READING something does not catch it; any mechanism acting on the PATH (exact-string) can.

## 4. Recommendation — one combination

**Core pair (mechanical): #6 + #4, ordered by DS, built by Claude, recorded via the Owner's push protocol.**
1. **Delete `Sim/`, `core/`, `shared/` now** (0 files each, untracked — deletion is a working-tree act with no git footprint). Keep `sims/` as the designated destination until Pickle+DS decide otherwise.
2. **Install the CI tracked-file gate** in `.github/workflows/` with the exact-path list starting `Sim/`, `core/`, `shared/`, and joined by `sports/` paths the moment the KI-016 quarantine executes. Nothing is grandfathered (VERIFIED: no tracked files under any candidate dir today), so day one is clean.

**One channel line (advisory backing it):** a pointer in **AGENTS.md** (the auto-injected channel every OpenCode session receives before its first turn) naming `sims/` as the per-sim destination and stating the non-authoritative list — not replacing the mechanical pair, only de-briefing new sessions faster than the CI failure does. In the same stroke, DS resolves the **two-architecture-docs duality** (choose the canon between `docs/ARCHITECTURE.md` and `SIM-PLATFORM/ARCHITECTURE.md`, supersede the other, strip the banned "V21" label from whichever survives).

**Why these three and not the rest of the six:** READMEs and canonical docs act only on sessions that read them — and the headline case (#2's near-homonym) is defined by never reading anything on the wrong path. CODEOWNERS blocks only merges in a council whose dominant event is a local write behind a single admin. Pre-commit hooks replicate per-clone and bypass silently; brief lines are compliance, not enforcement. Deletion removes the present ambiguity but is resurrected silently by the next write — which is exactly what the CI gate converts into a loud, path-named failure at record time. The pair covers each other: deletion cannot be bypassed by forgetting, CI cannot be exhausted by recreation.

**Reference gate sketch (for Claude's build — NOT installed by me; my lane is `_agents/glm/`):**

```yaml
# .github/workflows/layout-guard.yml (sketch)
- name: no tracked files under non-authoritative paths
  run: |
    set -e
    BAD="Sim core shared"
    # append quarantine paths when executed: sports
    FOUND=$(git diff --name-only --diff-filter=ACMR "${{ github.event.before }}" "${{ github.sha }}" | awk -F/ '$1=="Sim"||$1=="core"||$1=="shared"{print}')
    [ -z "$FOUND" ] || { echo "non-authoritative paths touched: $FOUND"; exit 1; }
```

**What would change this recommendation:**
1. **The Pickle+DS topology call relocates the per-sim destination** (e.g., into `SIM-PLATFORM/projects/` per sim) → `sims/` joins the deletion list and the gate list grows by one; nothing else changes.
2. **CI is unavailable at repo level** (Actions disabled and stays that way, or the Owner declines repo edits) → substitute a **publish-time guard**: the path guard runs inside `tools/build-merged.js` or `sync-mirrors.sh`, i.e., at every push-conveyor step instead of at commit time. Weaker — it depends on the human conveyor remembering — and must be logged as such in STATUS until CI lands.
3. **The AGENTS.md line is not relayed** (Owner-assigned-edit-only protocol) → the pointer moves to ONBOARDING.md v2 (the standardized paste) and into every dispatch brief; the residual gap — long-lived sessions that never re-open the template — is accepted and logged.
4. **Non-OpenCode agents join the council** → the auto-injection claim shrinks from "every session" to "every OpenCode session"; the AGENTS.md line must then also ride in briefs (belt and suspenders affirmed in writing).
