## The node batteries on a current Node (the Part-4 note)
- The engine snapshot carries a TypeScript **parameter property** (`platform/localstorage.ts`,
  `constructor(private readonly ls: Storage | null, …)` — **still at the tip, checked this sitting**)
  — strip-only mode cannot parse it (`ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`). Both
  `batteries/node.battery.mjs` and `batteries/shell.battery.mjs` import the port node-side, so BOTH
  need the transform flag: `node --experimental-transform-types batteries/node.battery.mjs` (in
  package.json as `battery:node`) and `node --experimental-transform-types batteries/shell.battery.mjs`.
- **Verified on Node v24.22.3** (route 1 of the Part-4 options: run on a Node that supports the
  flag; pin the version). On a Node where the flag is removed (Node 26+): use route 2 (precompile
  the snapshot's parameter property into a generated copy outside `src/engine/`) or route 3
  (§5 filing to the Architect to replace the one parameter property with explicit fields — a
  no-behaviour-change edit the shell cannot make itself, filed 2026-11-17, re-checked at 5c808472).
