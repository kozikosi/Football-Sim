Reading note (honest caveat): the FOUND/NEW headers were introduced 3 Nov 2026, so most counted reviews are first reviews of their item — where every finding is unique by definition and catch reads 100%. The number that matters is the catch rate of later reviews on the same item (the governor's <10% stopping rule); the JSON keeps the item IDs so that curve can be drawn as the two-reviewer dataset grows.
