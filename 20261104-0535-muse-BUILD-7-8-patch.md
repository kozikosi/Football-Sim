## Patch form

**Target build:** `tools/council.mjs` on `origin/architect/engine-and-seats`, with BUILD-1..6 applied.

**WHERE (anchor):** In `main()`, after the `else if (cmd === 'dod') {` block.

**Old → new:** See the patch file. Two new commands:

**BUILD-7: `quote <file> <text>`**
Verifies a quoted string appears in the cited file. Resolves the file locally, then via `g('show')` on origin/council/* branches. Outputs FOUND with line numbers, or NOT FOUND with up to 3 suggested lines containing the quote's numbers.
- Example: `quote inbox/...-muse-review.md "CB1 0.70"` → NOT FOUND (VL's invented value)
- Example: `quote inbox/...-muse-review.md "SS 0.70"` → FOUND at line 10

**BUILD-8: `review-skeleton <ID>`**
Prints a review template with required SOURCE field for each finding:
```
SOURCE: <file>:<line> "<exact quote from the source>"
```
The template makes it structurally difficult to paraphrase numbers from memory — the SOURCE line demands the exact quote.

**WHY:** Owner-flagged frequent problem. A seat disputed MUSE's reported P-219 values by quoting numbers MUSE never wrote (reconstructed from memory). The existing VERIFIED/REPORTED labels cover the reporter's evidence, not the disputant's accuracy. These two commands make verification cheap (one command) and misquoting visible (NOT FOUND output).

**SAFE ALONE?** Yes. Two new commands, no existing behavior changed. The `g()` helper swallows git errors. The `fs` module is already imported.

**HOW TO CHECK:**
```
node --check tools/council.mjs
node tools/council.mjs quote <file> "nonexistent 123.45"
# expect: NOT FOUND
node tools/council.mjs quote <file> "<known string>"
# expect: FOUND with line number
node tools/council.mjs review-skeleton P-999
# expect: template with SOURCE field
```

**Tested:** `node --check` passes. Quote verified: "CB1 0.70" → NOT FOUND (correct), "SS 0.70" → FOUND at L10 (correct). Skeleton outputs valid template.

**Not in scope:** Enforcing SOURCE field usage (that's a review norm, not toolable). Other seats may propose alternative solutions to the misquoting problem.
