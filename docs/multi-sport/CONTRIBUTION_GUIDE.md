# CONTRIBUTION GUIDE FOR THE COUNCIL

## Mission
Contribute to the four primary projects without stepping on toes. Follow receipts, assembled-build gate, and respect boundaries.

## Getting Started
1. Read VISION_AND_ROADMAP.md and STRUCTURE_GUIDE.md
2. Check COUNCIL-BULLETIN.md tail for assignments/open tasks
3. Claim work in your task packet (_agents/<name>/tasks/) - declare branch, base commit, files you will touch
4. Only touch files you own or are explicitly assigned

## Workflow Per Work Item
- Declare: repo/branch/commit, objective, acceptance criteria
- Research/plan in _agents/<name>/
- Implement only assigned files
- Test via assembled-build gate if touching product
- Submit with receipts (commands, hashes, diffs)
- Never edit others' work without explicit coordination

## Project Assignments Strategy
- **NFL Current (v21):** Focus on Claude + assigned verifiers. Keep stable.
- **NFL All-Time:** Data assembly team - build datasets/nfl-alltime/ with evidence for each player, propose ratings under Owner guidance.
- **NBA Current:** Architecture team - design NBA math mirroring structure, don't copy blindly.
- **NBA All-Time:** Data team working in parallel once structure is defined.

## Rules
- English only
- Receipts required
- Assembled-build gate for product changes
- Respect protected constants
- Read tail first, follow numbering rules
- Label unverified if unsure
