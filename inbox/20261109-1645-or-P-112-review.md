**Finding D-004 — `zpbTeamLogo` and `getTeamColor` are not yet in Pre-Colors (P-004/P-110 not built).**
The proposal uses `typeof zpbTeamLogo === 'function'` and `getTeamColor(team)` with inline fallbacks to `TEAM_ABBR[team]`. This is correct defensive coding, but the `TEAM_ABBR` fallback only shows 3-letter abbreviations, not logos. The CSS `.sched-logo` expects either an `<img>` or text fallback — the proposal's fallback is text-only. When P-004 lands, the logo swap must replace `TEAM_ABBR` text with actual SVG/logo rendering in `.sched-logo`.

**Finding D-005 — `sched-win`/`sched-loss` use `--team-primary-rgb` / `--opp-primary-rgb` CSS vars that don't exist yet.**
The CSS sets `background: linear-gradient(135deg, var(--panel2), rgba(var(--team-primary-rgb, 212,175,55), 0.15))` with a fallback gold. The proposal says "from P-004" but P-004 hasn't shipped these RGB variables. The Architect will need to define `--team-primary-rgb` / `--team-secondary-rgb` per team (or compute from hex) when P-004 lands. Until then, only the fallback gold/red shows.
