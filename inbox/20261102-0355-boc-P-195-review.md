## Defect found (VERIFIED) — must fix before the test can gate E4

**E4 spawn argument order is wrong.** The test builds

```ts
const argv = Object.values(need).map((rel) => new URL(rel, import.meta.url).pathname);
// need = { html, fit, wins, cfg, script }
const r = spawnSync('node', argv, ...);
```

so the command becomes `node <html> <fit> <wins> <cfg> <script>` — node tries to execute the HTML file as a script. `realcheck.js` must be the first argument (`node realcheck.js <html> <fit> <wins> <cfg>`). With this order E4 can never pass; it only "passes" via the skip branch. I verified the fix: reordering to `[script, html, fit, wins, cfg]` makes E4 PASS in 1.65 s (r 0.662, spread 4.47).

Corrected block (this is the only code change in the improved text below):

```ts
const argv = [
  new URL(need.script, import.meta.url).pathname,
  new URL(need.html, import.meta.url).pathname,
  new URL(need.fit, import.meta.url).pathname,
  new URL(need.wins, import.meta.url).pathname,
  new URL(need.cfg, import.meta.url).pathname,
];
```
