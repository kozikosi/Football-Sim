## CSS cascade approach

```css
:root {
  --team-primary: #d4af37;   /* rose/gold default until team chosen */
  --team-secondary: #f0dce2;
  --team-accent: #ffffff;
  --team-primary-rgb: 212,175,55;
}
[data-team] {
  --team-primary: var(--tp, #d4af37);
  --team-secondary: var(--ts, #f0dce2);
  --team-accent: var(--ta, #ffffff);
}
```

```javascript
const TEAM_COLORS = { /* 32 entries above as [p,s,a] */ };
function applyTeamColors(teamName) {
  const [p, s, a] = TEAM_COLORS[teamName] || TEAM_COLORS['Kansas City Chiefs'];
  const r = document.documentElement;
  r.style.setProperty('--tp', p);
  r.style.setProperty('--ts', s);
  r.style.setProperty('--ta', a);
  r.dataset.team = teamName;
  // darker/paler tones for legibility: derive --team-primary-dark = p at 80% lightness
}
```

## Application rules (from V23-OWNER-REQUESTS + Owner answers)

1. Rose until a team is chosen. Home / Season / Playoffs tabs stay rose. Other tabs take the near-white team tint.
2. Once a team is chosen and the draft starts, that team's 3 hexes transform the whole app (darker/paler tones allowed for legibility).
3. Draft board: each player framed by the 3 colours of the real NFL team he is on, until the draft ends. After the draft, your players framed by your team's colours; other teams' players by theirs. Neutral = white; no black/grey except dark mode's black.
4. Each player's draft card keeps the colours of their real NFL team until the draft ends.
5. Opponent-team players keep their own team's colours (never the user's).
6. Similar-colour fallback: if primary == secondary (e.g. Raiders #000000 / #A5ACAF), use accent as the second visible colour.

## Dark-mode legibility

Dark teams (Patriots #002244, Ravens #241773, Rams #003594, Titans #0C2340) need a paler tone for text on dark backgrounds. Derive `--team-primary-light = lighten(primary, 30%)` for small text. Owner flagged these as unreadable.
