## Where drive.ts assumes a flat rate (VERIFIED)

`colors/src/engine/drives.ts`:
- Line 169: `for (const s of ['home','away']) for (let i = 0; i < comp[s].fg; i++) if (chance(rD, 0.176)) mfDraw[s]++;`
  - This is the regulation missed-FG draw: each planned FG (3 pts, from `decompose`) has a 17.6% chance of becoming an extra missed-FG drive. Implied make rate = 1 / (1 + 0.176) = **85.0%**, distance-independent. Consistent with the measured 85.2% overall, but ignores distance.
- Line 225 (overtime `play()`): `end = chance(rO, 0.87) ? 'FG' : 'FG_MISS'` — a **second, different** flat rate (87%), used for OT drives. Inconsistent with regulation (85.0%) and with measured (85.2%), but within ~2 points.

## Proposed changes (INFERRED, for the Architect's verdict)

1. **Refine `kicking.ts` CURVE to the measured values** (league-average baseline). Proposed breakpoints:
   ```
   [18, 0.995], [30, 0.96], [40, 0.83], [45, 0.76], [50, 0.73], [55, 0.62], [60, 0.43], [65, 0.31], [70, 0.12]
   ```
   These are the measured 5-yard-band make percentages at the nearest band; the 70+ value is uncertain (n=2) and kept conservative.

2. **Align the two flat rates.** Regulation implies 85.0% (0.176 miss draw); OT uses 87%. Set OT to 0.85 (i.e. `chance(rO, 0.85)`) or, better, make it distance-aware: draw a distance from the attempt distribution and use `leagueMakeProb(dist)`:
   ```ts
   const fgDist = drawFgDistance(rO);   // from measured attempt distribution
   end = rO.next() < leagueMakeProb(fgDist) ? 'FG' : 'FG_MISS';
   ```
   OT drives are single-drive outcomes not tied to a pre-decomposed score, so this is safe there.

3. **Regulation:** makes are fixed by `decompose()` (c.b field goals = 3 pts each), so the make count cannot be randomized without changing the score. Keep the 0.176 miss draw (it already matches the 85% overall). Optionally, assign a distance to each FG/FG_MISS drive (drawn from the measured distribution) and record it on the drive/stats for the recap and in-season kicker rating, without changing scores. This is a larger change (Drive gains a `fgDist` field) and is deferred.

4. **Distance draw helper** (for OT and, later, regulation stats), from the measured attempt distribution:
   ```ts
   // cumulative attempt shares by 10-yd band (20-29 21.9, 30-39 28.1, 40-49 28.5, 50-59 20.0, 60+ 1.2, <20 0.3)
   function drawFgDistance(rng: Rng): number {
     const u = rng.next();
     const bands = [[18,29,0.003],[20,29,0.219],[30,39,0.281],[40,49,0.285],[50,59,0.200],[60,74,0.012]];
     let acc = 0;
     for (const [lo,hi,w] of bands) { acc += w; if (u < acc) return lo + Math.floor(rng.next() * (hi - lo + 1)); }
     return 39;
   }
   ```
