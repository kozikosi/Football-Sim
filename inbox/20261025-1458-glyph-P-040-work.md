## Cropping / no bubble behind logos
- Prefer **SVG** where possible (vector, clean edges, easy to scale). 
- For PNG: use `object-fit: contain` with transparent background; avoid adding colored bubble backgrounds behind logos. If source has padding/white space, crop with CSS by using `overflow: hidden` + `object-position: center` and/or preprocess (ImageMagick `convert -trim +repage` / `magick`) to remove whitespace while keeping transparency. Also ensure `background: transparent` and no panel/border circle unless explicitly requested.
- For 390px: cap logo height (e.g. 28-36px) to avoid growing; use `max-height` not scaling up on compress.
