### Punter's 1.084 coefficient

The spec (§3, Punter bullet) says PUNT_PTS went from 1.6 to 1.084. The punter's value comes from field-position flipping: a better punter increases net yards per punt, which changes expected starting field position for the opponent.

With 3.6 punts/game and 41.1 net yards/punt:
- Total punting yards per game: 3.6 × 41.1 = 148.0 net yards
- A 10-point punter rating improvement (80→90) changes net yards by approximately 2-3 yards/punt (based on the exp() model in the spec)
- At 3.6 punts/game, that's ~7-11 net yards/game of field position
- The 1.084 coefficient converts this to ~0.25 wins for a 70→90 punter (half a kicker), which matches the spec's claim.

The 1.084 is FITTED (not design) and depends on the exp((p-80)/45) formula. It is VERIFIED in the lab (apply-math-patch.mjs checks PUNT_PTS 1.084→2.4 fails E10).

## Analysis: is the RET_PTS split (1.50/0.86) justified?

### Current split
- Kick: 1.50 (63.6% of 2.36)
- Punt: 0.86 (36.4% of 2.36)

### What the data says

**Yardage ratio (2025):**
- Kick return yards: 99.0/game (86.5% of total return yards)
- Punt return yards: 15.5/game (13.5% of total return yards)
- Ratio: 6.4:1 (kick:punt)

**Return frequency:**
- Kick returns: 3.8/game
- Punt returns: 1.5/game
- Ratio: 2.5:1

**Yards per return:**
- Kick: 25.9 yards/return
- Punt: 10.2 yards/return
- Ratio: 2.5:1

### Assessment

The current split gives kick returns 63.6% of RET_PTS, but kick returns produce 86.5% of return yards. This suggests kick returns may be underweighted relative to their yardage contribution.

However, the model's return term is `KR_PTS·(exp((kr−82)/45) − exp((lg.kr−82)/45))`, which measures the MARGINAL value of a better-than-average returner, not absolute yards. The marginal value depends on:
1. The rating distribution of returners in the draft pool
2. The exp() curvature (diminishing returns at high ratings)
3. The leverage of each return type (a punt return that flips field position may be worth more per yard than a kick return)

**Key consideration:** Punt returns have higher leverage per yard because they occur in situations where field position is more valuable (after a punt, the receiving team starts deeper; a good return flips more expected points). Kick returns in 2025 start from the 30-yard line on average (new rules), reducing the marginal value of return yards.

**2025 rule change impact:** The dynamic kickoff rule increased kick returns from 1.7 to 3.8 per game and from 46.7 to 99.0 yards per game. This is a 2.1x increase in kick return volume. If the model was calibrated on pre-2025 data (1.7 returns/game), the kick return value may need to increase to reflect the new rules.

### Proposed corrected split

Given the 2025 data (kick returns 6.4x more yards, 2.5x more frequent), but accounting for leverage differences:

**Option A (yardage-weighted):** Kick 1.86 / Punt 0.50 (total 2.36)
- Pro: matches the 86.5/13.5 yardage split more closely
- Con: ignores leverage differences; may overvalue kick returns

**Option B (leverage-adjusted):** Kick 1.70 / Punt 0.66 (total 2.36)
- Pro: accounts for higher per-yard leverage of punt returns
- Con: the 0.66/0.36 split is arbitrary without a fitted model

**Option C (retain current, adjust for 2025 rules):** Kick 1.60 / Punt 0.76 (total 2.36)
- Pro: modest increase in kick share reflecting 2025 volume increase
- Con: still underweights kick returns by yardage

**Recommendation:** The current 1.50/0.86 split is defensible as a design choice given the leverage argument, but the 2025 rule change (2.1x more kick returns) suggests kick returns should be weighted more heavily. I recommend Option B (1.70/0.66) as a starting point, with the caveat that the exact split requires simulation runs (like recv-plan-experiment.js) to verify that TE1/KR values are preserved.

**What the data cannot tell us:**
1. The marginal value of a better returner depends on the rating distribution in the draft pool, which we don't have.
2. The exp() curvature means the split's effect is non-linear — a 0.1 change in KR_PTS has different effects at different rating levels.
3. The 2025 rule change may be temporary (the league has adjusted kickoff rules before); calibrating to 2025 data risks overfitting to a single season.
4. The leverage difference between kick and punt returns (expected points per yard) is not quantified in the available data.
