## VLOC-D1: The Role-Adjacency Deficit Model

**Core idea:** the cost of playing destination D from source S is how much of D's job S cannot do, measured duty-by-duty and aggregated into one raw score.

**Formula** (sport-agnostic; only roles/duties/inputs change per sport):
1. For each duty d: gap[d] = max(0, need[D][d] − have[S][d]) × weight[d]  (scope-filtered: THR only for QB, KCK only for K, PNT only for P)
2. Sort weighted gaps descending: w₁ ≥ w₂ ≥ ...
3. raw = w₁ + φ·Σ min(g, w₁) for trailing gaps — bottleneck full, breadth discounted, each trailing gap capped at the bottleneck
   - φ = 0.4. NOT ZAI-D1's M + λ·S (uncapped sum of trailing deficits).
4. Tier via cuts 1/4/9 → tiers 0/2/6/12.
5. Cross-side floor 6 (offense↔defense, non-specialist, dst ≠ FB).
6. Archetype cost: +1 raw when a non-DB source plays a DB destination (SS/FS/CB/NICKEL/DIME) and duty gap > 0. Zero-gap transitions stay free.

**NO D term, NO fiat rows, NO named overrides.** Every parameter is a football-reasoned duty weight / have / need score.

**Duties (16):** PBLK, RBLK, SNP, CTH, RTE, CARRY, THR, MCOV, ZCOV, RNG, ERUSH, BRUSH, RDEF, TKL, KCK, PNT
(MCOV/ZCOV split man vs zone coverage; ERUSH/BRUSH split edge rush vs interior/blitz rush — captures key asymmetries like OLB can blitz but not edge-rush.)

**Fit to live table (@ 97d7e9d):** exact 84 / off-1 15 / hard 0 / tier-error 15.
Every disagreement is exactly one tier — no hard misses.

**15 off-by-ones cluster:**
- Model 2, owner 6 (8): EDGE→ILB, EDGE→NICKEL, FS→DIME, FS→OLB, OLB→ILB, OLB→NICKEL, OLB→OLB, SS→CB
- Model 6, owner 12 (5): EDGE→SS, ILB→FS, OLB→DIME, OLB→FS, TE→SS
- Model 2, owner 0 (2): CB→FS, OLB→OLB

**Cross-sport:** same formula runs for basketball — substitute roles (PG/SG/SF/PF/C), duties (ball handling, 3pt shooting, rim protection, etc.), HAVE/NEED matrices, and weights. Not built yet (basketball waits for 76 Pancakes per Owner).
