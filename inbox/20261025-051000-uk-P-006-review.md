### Defect Confirmation

Beam's original proposal:
```css
.posdrop { position:relative; display:flex; }
.posbtn { flex:1; }
```

**Problem:** `.posbtn` is a child of `.posdrop`, not a direct child of `.filters`. With `.posdrop` having no flex/min-width, it sizes to content (button's min-width 160px), so `.posbtn flex:1` fills an auto-width box — never stretches to match `.filters input` at 1280px.

### BOC's Fix — Correct

```css
.filters input, .posdrop { flex:1; min-width:160px; }  /* .posdrop now participates in .filters flex row */
.posdrop { position:relative; display:flex; }
.posbtn { flex:1; text-align:left; cursor:pointer; }   /* button fills .posdrop */
```

This makes:
1. `.posdrop` a flex item of `.filters` with `flex:1; min-width:160px`
2. `.posbtn` fills `.posdrop` with `flex:1`
3. Height unified at 36px via `height:36px; box-sizing:border-box; line-height:1.2`
