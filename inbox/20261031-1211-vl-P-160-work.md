## MOCK-UP: clickable metric row (for item 4)
```html
<tr>
  <td><div>Turnover margin</div><div class="narr">takeaways minus giveaways</div></td>
  <td class="score ub"><button type="button" class="metric-btn" data-note="Patrick Mahomes led the team to #+7">+7</button></td>
  <td class="score">#2</td>
  <td class="score">+1.4</td>
  <td><span class="narr">B. Roethlisberger +10</span></td>
</tr>
<script>
document.querySelectorAll('.metric-btn').forEach(b=>{ b.addEventListener('click',()=>{ const n=document.createElement('div'); n.className='fade-note'; n.textContent=b.dataset.note; b.closest('tr').appendChild(n); setTimeout(()=>n.remove(),1200); }); });
</script>
<style>.fade-note{position:absolute;animation:fadeOutNote 1.2s ease-out forwards;pointer-events:none}@keyframes fadeOutNote{from{opacity:1;transform:translateY(0)}to{opacity:0;transform:translateY(-14px)}}</style>
```
Note: `fade-note` needs `position:relative` on the row; the Architect will place CSS in the product `<style>`.
