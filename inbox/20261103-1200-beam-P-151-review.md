   (six variables). The snippet's `.shm-btn` uses only `--b1/--b2/--b3`. This silently

   hardcodes `rgba(0,0,0,.15)`, fixed rgba shadows, `#3a2600`, and drops `Bodoni Moda`/`Didot`.
   For a copy-paste snippet this is acceptable, but defaults should be theme vars with
   fallbacks so the snippet degrades gracefully inside the app. Improved snippet below
   keeps the hardcoded defaults but documents the source vars.

   Architect does not treat them as verbatim. (Work file does say "INFERRED" for CSS

   work file's own rule "Never use both full-shimmer effects on the same screen — they
   compete. One hero shimmer per view." Demo-only, but should be split into separate
