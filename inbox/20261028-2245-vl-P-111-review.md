## What breaks (trying to break it)

1. **`html{font-size:21px;}` changed to `14px`** (proposal CSS section 2). The product uses 21px as its base font size (l.2). Changing to 14px would shrink every rem/em-based measurement across the entire 650KB product. Not justified by the owner's request (which is about font family, not size).

2. **`--gold` overridden to `#b8941f` in light mode** (proposal CSS section 5). `--gold` is `#ffc43c` at l.217 and used throughout the product (draft board, buttons, badges, etc.). Changing it for light mode creates inconsistency. Also `--gold-light` is referenced but doesn't exist.

3. **Font files don't exist in the repo.** The proposal requires 6 WOFF2 files (Cinzel Decorative 700/900, Bodoni Moda 500/600/700) that are not in the repository. The product is a single self-contained HTML file — relative paths to `fonts/` won't work when opened standalone. Base64 embedding would bloat the file significantly (each WOFF2 is ~30-60KB, 6 files = ~200KB+ added to a 650KB file).

4. **`!important` overrides** (proposal CSS section 2, lines 146-227) — could conflict with existing styles and make future overrides difficult.

5. **`textShimmer`/`foilShimmer` keyframes don't exist.** The `.foil-shimmer` class uses `animation: foilShimmer 2.5s ease-in-out infinite` but this keyframe is not defined in Pre-Colors. Needs to be added.

6. **`Cinzel Decorative` not loaded.** Without the font files, `var(--font-display)` falls back to Georgia/serif, which doesn't achieve the owner's intent.

7. **`--rose` referenced but doesn't exist.** Used in `.foil-shimmer.rose` with fallback `#c97a8e`. `--rose` is not a defined CSS variable in Pre-Colors.
