### 1. Font Loading: Local `@font-face` (No CDN)

**Download and bundle** Cinzel Decorative (700, 900) and Bodoni Moda (500, 600, 700) as WOFF2. Convert to base64 for inline `@font-face` or place in same directory.

```css

  font-family: 'Cinzel Decorative';
  src: url('fonts/CinzelDecorative-Bold.woff2') format('woff2'),
       url('fonts/CinzelDecorative-Bold.woff') format('woff');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: 'Cinzel Decorative';
  src: url('fonts/CinzelDecorative-Black.woff2') format('woff2'),
       url('fonts/CinzelDecorative-Black.woff') format('woff');
  font-weight: 900;
  font-style: normal;
  font-display: swap;
}

/* Bodoni Moda — secondary display (headers, section titles) */
@font-face {
  font-family: 'Bodoni Moda';
```

### 3. Foil Shimmer Style (Named & Standardized)

**Named Style:** `.foil-shimmer` (or `.foil`)

```css
/* ===== FOIL SHIMMER STYLE ===== */
/* Named: "foil shimmer" — gold gradient sweep across text */

.foil-shimmer {
  background: linear-gradient(90deg, 
    var(--gold) 0%, 
    #fff 35%, 
    var(--gold) 65%, 
    #fff 100%
  );
  background-size: 200% 100%;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
  color: transparent;
  animation: foilShimmer 2.5s ease-in-out infinite;
  display: inline-block; /* required for background-clip */
  font-family: var(--font-display);
  font-weight: 700;
}

.foil-shimmer.gold {
  /* Standard gold sweep */
  background: linear-gradient(90deg, 
    var(--gold) 0%, 
    #fff 35%, 
    var(--gold) 65%, 
    #fff 100%
  );
}

.foil-shimmer.team {
  /* Team-colored sweep (requires P-004 team theming) */
  background: linear-gradient(90deg, 
    var(--team-primary) 0%, 
    var(--team-secondary) 35%, 
    var(--team-primary) 65%, 
    var(--team-secondary) 100%
  );
  background-size: 200% 100%;
}

.foil-shimmer.rose {
  /* Rose-gold for champion/20-0 */
  background: linear-gradient(90deg, 
    var(--rose, #c97a8e) 0%, 
    #fff 35%, 
    var(--rose, #c97a8e) 65%, 
    #fff 100%
  );
}

@keyframes foilShimmer {
  0%   { background-position: 200% 0; }
  50%  { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

/* Reduced motion */
@media (prefers-reduced-motion: reduce) {
  .foil-shimmer { 
    animation: none; 
    background-position: 0 0; 
  }
}

/* Light mode adjustments */
@media (prefers-color-scheme: light) {
  :root:not([data-theme="dark"]) .foil-shimmer.gold {
    background: linear-gradient(90deg, 
      var(--gold-light, #d4a843) 0%, 
      #2a1a20 35%, 
      var(--gold-light, #d4a843) 65%, 
      #2a1a20 100%
    );
  }
}
```

**Usage:**
```html
<!-- Champion banner -->
<h2 class="foil-shimmer gold">CHAMPION</h2>

<!-- "Can you go 20-0?" -->
<span class="foil-shimmer rose">Can you go 20-0?</span>

<!-- Team name in team colors -->
<span class="foil-shimmer team">KANSAS CITY CHIEFS</span>

<!-- Player name 90+ OVR -->
<span class="foil-shimmer gold">Patrick Mahomes</span>

<!-- Start Draft button -->
<button class="resetbtn foil-shimmer gold">START DRAFT</button>
```
