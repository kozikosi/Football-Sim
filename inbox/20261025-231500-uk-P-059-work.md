# WORK: P-059 — Homepage Dropdowns Stay Side-by-Side on Mobile

**Seat:** UK (S-2200–2299) | **Claimed:** 2026-10-25T23:15:00Z | **Tier:** P0 | **Status:** WORK

---

## Source Requirement (Owner 25 Oct)

> "On the homepage, as the screen becomes smaller the dropdown menus should become smaller and stay in their same positions side by side, not stack on top of each other."

---

## Current State Analysis

**Location:** Homepage draft setup panel, selector row with team select and pick select.

**Current behavior:** On mobile (≤480px), `.selector-row` uses `flex-direction: column` causing dropdowns to stack vertically.

**Target behavior:** Dropdowns shrink but stay horizontal side-by-side at all widths.

---

## Proposed Implementation

### CSS Fix (in `<style>` block)

```css
/* P-059: Homepage dropdowns stay horizontal on mobile */
.selector-row {
  display: flex;
  gap: 0.5rem;  /* reduced gap on mobile */
  flex-wrap: nowrap;  /* prevent wrapping */
  justify-content: center;
  align-items: center;
}

.selector-pill {
  flex: 0 1 auto;  /* don't grow, shrink if needed */
  min-width: 0;    /* allow shrinking below content */
  padding: 0.5rem 1rem;  /* reduced padding */
  font-size: 0.8rem;     /* smaller font */
}

.selector-pill select {
  min-width: 100px;  /* reduced from 140px */
  font-size: 0.8rem;
}

/* At very narrow widths, allow slight wrap but keep compact */
@media (max-width: 360px) {
  .selector-row {
    gap: 0.375rem;
  }
  .selector-pill {
    padding: 0.375rem 0.75rem;
    font-size: 0.75rem;
  }
  .selector-pill select {
    min-width: 80px;
  }
}
```

**Key changes:**
- `flex-wrap: nowrap` prevents stacking
- `flex: 0 1 auto` allows shrinking but not growing
- `min-width: 0` on flex items allows them to shrink below content width
- Reduced padding/font-size on mobile
