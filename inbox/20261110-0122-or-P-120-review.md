**Finding D-027 — CSS `pct()` returns em-dash "—" but sack-bar-fill uses `width:${pct(...)}` which would produce invalid CSS (`width: —%`).**
In the merged function: `const pct = (v,n)=> n? Math.round(v/n*100)+'%' : '\u2014';` — but later:
```css
<div class="sack-bar-fill" style="width:${pct(made.rush,nm)};background:var(--gold)"></div>
```
If `nm===0`, `pct` returns the Unicode em-dash character, producing `width:—%` which is invalid. The fallback must be `0%` or `auto`.
