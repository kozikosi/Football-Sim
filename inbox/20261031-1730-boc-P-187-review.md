2. **DRAFT shimmer uses `var(--accent)` (blue), not gold.** The work's `.welcome-cine__text--draft` uses `var(--accent)` for the gold shimmer gradient. In Pre-Colors, `--accent` is `#4f8cff` (blue), not gold. The Owner's gold is `--gold: #ffc43c`. The shimmer should use `var(--gold)`. Flag.

3. **CSS animation shorthand overrides the shimmer.** The work declares two separate `animation` properties on `.welcome-cine__text--draft`:
   ```css
   animation: welcome-shimmer 2.5s linear infinite;
   /* later: */
   animation: welcome-fade-in 500ms ... 4200ms forwards;
   ```
   The second declaration overrides the first (CSS shorthand replaces, not appends). So the shimmer is lost. Fix: combine into one declaration: `animation: welcome-fade-in 500ms ... 4200ms forwards, welcome-shimmer 2.5s linear 4700ms infinite;`. Flag.

4. **"Auto-complete after DRAFT lingers for 3s" contradicts "lingers until click".** The work's JS has a comment "Auto-complete after DRAFT lingers for 3s (or wait for click)" but the Owner says "DRAFT lingers... centre graphic stays until CONTINUE" (P-155). The welcome cinematic's DRAFT should linger until the user clicks (skip overlay handles it). The auto-complete comment is wrong. Remove it. Flag.

5. **Skip exit transition is undefined.** `finish()` adds `welcome-cine--exiting` class and listens for `transitionend`, but no CSS defines a transition for `welcome-cine--exiting`. The overlay never fades out; it just stays (or is removed by the timeout, which doesn't exist). Fix: add a CSS rule `.welcome-cine--exiting { opacity: 0; transition: opacity 300ms ease; }` and ensure `onComplete` is called after the transition (or immediately remove and call onComplete). Flag.

6. **`#fff6c4` in the shimmer gradient is near-white.** The Owner says "no white text" (P-005/P-183). The shimmer gradient uses `#fff6c4` (cream/white) as a highlight. Consistent with P-155 finding 7 (same issue). Recommend: use `var(--gold)` or a gold-tinted highlight instead of `#fff6c4`. Flag.

## Corrected implementation (key deltas vs proposal)

```javascript
function showWelcomeCine(onComplete) {
  if (window._welcomeCineShown) { onComplete?.(); return; }
  window._welcomeCineShown = true;

  const reduced = window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  const cine = document.createElement('div');
  cine.className = 'welcome-cine';
  cine.innerHTML = `
    <div class="welcome-cine__skip" aria-label="Skip cinematic" role="button" tabindex="0"></div>
    <div class="welcome-cine__text welcome-cine__text--welcome" aria-hidden="true">WELCOME</div>
    <div class="welcome-cine__text welcome-cine__text--to-the-draft" aria-hidden="true">TO THE DRAFT</div>
    <div class="welcome-cine__text welcome-cine__text--draft" aria-hidden="true">DRAFT</div>
  `;
  document.body.appendChild(cine);

  const finish = () => {
    cine.classList.add('welcome-cine--exiting');
    setTimeout(() => { cine.remove(); onComplete?.(); }, 300);
  };

  const skip = cine.querySelector('.welcome-cine__skip');
  skip.addEventListener('click', finish);
  skip.addEventListener('keydown', (e) => {
    if ([' ', 'Enter', 'Escape'].includes(e.key)) finish();
  });

  if (reduced) {
    // Show only DRAFT immediately, start draft
    cine.querySelectorAll('.welcome-cine__text').forEach(el => el.style.opacity = '0');
    const draft = cine.querySelector('.welcome-cine__text--draft');
    if (draft) { draft.style.opacity = '1'; draft.style.left = 'calc(50% + 60px)'; }
    skip.style.display = 'none';
    setTimeout(() => { cine.remove(); onComplete?.(); }, 100);
    return;
  }

  // Screen reader announcements
  const announce = (text) => {
    const a = document.createElement('div');
    a.setAttribute('role', 'status');
    a.setAttribute('aria-live', 'polite');
    a.className = 'sr-only';
    a.textContent = text;
    document.body.appendChild(a);
    setTimeout(() => a.remove(), 1000);
  };
  setTimeout(() => announce('Welcome'), 100);
  setTimeout(() => announce('To the draft'), 2700);
  setTimeout(() => announce('Draft'), 4300);
}
```
