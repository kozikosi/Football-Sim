# Pin-watch: tripwire for stale engine pins (tools/pin-watch.mjs)

## What it does
Detects when the engine tree has gone stale relative to a named commit. Ernie's F-5 design: count first, spot-hash every engine file second, manifest hash never alone. Runnable from a git archive extract (zero repo state needed in the tree-dir; git objects are read from the invoking repo cwd via `git show <commit>:<path>`).

## Deliverables
- `tools/pin-watch.mjs` — the tripwire.
- `tools/pin-watch-falsifier.mjs` — falsifies pin-watch itself (moved-anchor guard: exit 1 naming file + anchor, never green on a tampered tree).
- This filing — receipts incl. the live catch.

## Usage
`node tools/pin-watch.mjs <tree-dir> <named-commit>`
  e.g. `node tools/pin-watch.mjs . HEAD`        (worktree; git objects here)
  e.g. `node tools/pin-watch.mjs /tmp/extract 4ca9a071`  (archive extract)
Exit codes: 0 = pin holds; 1 = stale/mismatch (file + anchor named); 2 = usage.

Live catch — stale pin 4ca9a071 (the deployed engine moved from `colors/src/sports/nfl/engine`/25 files to `colors/src/engine`/26 files; README/CHECKSUMS still name 4ca9a071):
```
$ node tools/pin-watch.mjs . 4ca9a071
PIN-WATCH STALE (2 check(s) failed) @ 4ca9a071 in .
  engine dir tree: colors/src/engine   engine dir @4ca9a071: colors/src/sports/nfl/engine
  count tree: 26   count @4ca9a071: 25
  MISMATCH count: tree has 26 engine files, 4ca9a071 has 25
  spot awards.ts: tree=efdd16de875c commit=efdd16de875c (anchor colors/src/sports/nfl/engine/awards.ts)
  spot boxscore.ts: tree=bfc8e7cbf234 commit=1fac49c3e902 (anchor colors/src/sports/nfl/engine/boxscore.ts)
  spot display.ts: tree=439cdae411dc commit=439cdae411dc (anchor colors/src/sports/nfl/engine/display.ts)
  MISMATCH spot-hash boxscore.ts (anchor colors/src/sources/nfl/engine/boxscore.ts): tree bfc8e7cbf234 != 4ca9a071 1fac49c3e902
  manifest present: CHECKSUMS.txt (manifest hash alone is insufficient — verify the engine files it names)
EXIT=1
```
The tripwire catches the case it exists for: the live stale pin is RED, naming the mismatching file (boxscore.ts) and its anchor commit path.

## Falsifier receipt
```
$ node tools/pin-watch-falsifier.mjs . HEAD
PASS found an engine file to tamper — colors/src/engine/drives.ts
PASS tampered tree exits 1 (never green) — PIN-WATCH STALE ...
PASS exit 1 names the file — colors/src/engine/drives.ts
PASS exit 1 names the anchor — colors/src/engine/drives.ts
PASS restored tree exits 0 — PIN-WATCH OK @ HEAD ...
FALSIFIER OK: pin-watch detects the moved anchor, names file + anchor, and returns green when clean
EXIT=0
```
The falsifier extracts a clean archive, tamps `drives.ts`, confirms pin-watch exits 1 naming file + anchor, restores, confirms green. A tripwire that could not catch its own case would be green here; it is not.

## Design notes (why this shape)
- All engine files are compared by basename (not just three spot samples) so a tamper to any file is caught; the first three are shown as the reported sample.
- Engine directory is resolved per-ref (both `colors/src/engine` and `colors/src/sports/nfl/engine` layouts) because the engine moved between pins — this is exactly what caught the 4ca9a071 staleness (dir moved + count 26 vs 25).
- Manifest is noted but never trusted alone; count + spot-hash carry the check.
- Exit 1 always names the file and the anchor (commit path), per the moved-anchor guard.
