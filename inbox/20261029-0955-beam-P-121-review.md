## Additional findings vs review #1 (vl)

1. **`sg()` logic is trivially true.** The proposal uses `sg(Math.abs(planFx)) >= sg(Math.abs(luck))`. Since `Math.abs()` is always >= 0, `sg()` (if defined as `v=>v>=0?1:-1`) returns 1 for both sides, making the comparison always `1>=1` = true. The intent was likely to compare magnitudes: `Math.abs(planFx) >= Math.abs(luck)`. Fix the comparison, not just the missing function.

2. **IntersectionObserver lifecycle.** `setTimeout(initSIWScrollFade, 0)` runs once on initial render. Re-rendering the panel (e.g., after a game) leaves cards un-observed and stuck invisible. Either re-run on every render, or store the observer and re-observe. Also, `querySelectorAll('.siw-card')` is global — scope to the panel (`#siwContent .siw-card`).

3. **Default visibility.** Cards start at opacity 0 (presumably) and only become visible when observed. If JS fails or the observer never fires (e.g., cards above the fold with threshold 0.15), content stays invisible. Set default `opacity: 1` and only animate when `prefers-reduced-motion: no-preference`, or add a fallback timeout.

4. **Memory leak.** The observer is never disconnected. On repeated renders, observers accumulate. Add `observer.disconnect()` before re-init, or use a single persistent observer.

5. **Shimmer invisible on light backgrounds.** `.arc-record.shimmer`, `.pythag-fill.pos`, `.moment-score`, `.wf-val` use `linear-gradient(90deg, var(--gold), #fff, var(--gold))`. On near-white team tints, `#fff` vanishes. Use `var(--gold)` → `var(--gold-deep,#b8860b)` → `var(--gold)`.

6. **`#fff8e1` literal.** `.wf-final` uses `#fff8e1` background. Replace with `var(--gold,#ffc43c)` or define `--gold-light`.

7. **`qb.st.rating` doesn't exist.** vl flagged. The QB star card uses `${qb.st.rating.toFixed(1)} RTG`. Use `passerRating(qb.st.cmp, qb.st.att, qb.st.passYds, qb.st.passTD, qb.st.int)` (exists at l.2372) or drop the rating.

8. **Integers-only (P-183).** Multiple `.toFixed(1)` calls: PPG/PAPG, MARGIN, gap, myN, schedFx, planFx, luck, actual. vl flagged. Replace with `Math.round()` or integer.

9. **`factsBase()` shape.** The proposal destructures `{user, N, me, log, S}` from `F`. Verify `F.me` has `.pf`, `.pa`, `.gp`, `.wins`, `.losses`, `.ties`. The current `fragArc` uses these. OK (existing code).
