# Brag share spec

## Owner's locked words

"The user shouldn't be exporting anything. That's too much. No downloads. You could create a copy and paste sharable with a link to the project and uh 'I went x-y. Can you go 20-0?'" / "it's not a seed challenge. it's a brag share." / "no to the hidden full save."

## Behavior

1. **Location:** a share button on the season results screen only (after elimination — the same trigger as stats recording). Not on the draft screen, not mid-season.
2. **Action:** one tap → composes the text below → writes to clipboard → shows a confirmation toast.
3. **No downloads, no files, no parameters.** The share carries no save data, no seed, no state of any kind.

## Text template

```
I went {W}-{L} with the {Team} and {result}. Can you go 20-0?
{deployed_url}
```

- `{W}-{L}`: regular-season record only (e.g. "14-3").
- `{Team}`: full team name (e.g. "Chiefs").
- `{result}`: one of —
  - "won the Super Bowl" (champion)
  - "went 20-0" (undefeated champion; replaces "won the Super Bowl")
  - "lost in the Super Bowl" (runner-up)
  - "lost in the {round}" (conference championship / divisional / wild card)
  - "missed the playoffs" (no berth)
- `{deployed_url}`: the deployed game URL, bare. Never `file://`, never localhost, never with query params or encoded state.

**Example:** `I went 17-0 with the Chiefs and went 20-0. Can you go 20-0? https://<deployed-url>`

## URL rule

The URL is a build-time constant (the deployed origin + path). It is not constructed from `window.location` — a developer opening the shipped file from `file://` must not share a `file://` link. If the constant is unset (dev build), the button is hidden, not shown with a broken link.

## Clipboard + toast

- **Success:** toast reads "Copied — go brag." (one line, no exclamation-mark inflation).
- **Clipboard unavailable** (permissions, insecure context): fall back to a readonly textarea with the text preselected and the toast "Copy it yourself — clipboard's blocked." Never fail silently.
- **No analytics, no share-target picker.** Clipboard only.

## Edge cases

- **20-0 season:** the `{result}` is "went 20-0", not "won the Super Bowl" — the thesis stat gets the marquee phrasing.
- **Run-it-back seasons:** share text is identical; no "run it back" annotation. A season is a season.
- **Multiple slots:** the share always describes the season on the results screen being viewed, never another slot.
- **Empty clipboard write of empty text:** impossible by construction — the button only exists on a completed (eliminated) season screen, where W, L, team and result are all known.

## Out of scope (explicitly not built)

- Seed challenges, encoded states, deep links into a specific season.
- Social SDKs, Web Share API target pickers, image cards.
- The hidden full-save clipboard backup (Owner rejected).
