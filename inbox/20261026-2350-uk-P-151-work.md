## 85+/90+ USAGE NOTES

### For 85-89 OVR Players
- "Can you go" text: Team primary color (breathing fade)
- "20-0?": Gold foil shimmer
- No full foil shimmer on "Can you go"

### For 90+ OVR Players
- Entire phrase "Can you go 20-0?": Full foil shimmer sweep
- Team color breathing on "Can you go" (optional)
- Gold shimmer on "20-0?"

### Implementation Pattern

```javascript
function apply200Shimmer(element, ovr, team) {
  element.dataset.team = team;
  if (ovr >= 90) {
    element.classList.add('shimmer-all');
    element.querySelector('.cyg')?.classList.add('shimmer-all');
  } else if (ovr >= 85) {
    element.querySelector('.cyg')?.classList.add('team-color');
  }
}
```
