## Innovation / brainstorm (for the Architect, not a blocker)

The late-round simple board is the right idea. Extensions worth a P-item:

1. **One-click "best available" fill for the last 4 rounds.** Once lateMode is on and the needs row is empty, a single "FILL REST" button that dispatches the top candidate (by the existing wins rank) into the best-fit slot for each remaining pick, with an undo. Keeps the user in the loop (one click, not zero) but removes the math. The engine already ranks by wins; this is pure presentation.
2. **A "round 11+ summary card" instead of a full board row.** In simple mode, collapse each remaining team's needs into a one-line "needs: DT, CB" pill and show only the user's own row expanded. Reduces scroll on mobile (390px) — L5 already proves 390px clean, but density could drop further.
3. **Persist simpleOff per save.** Currently `simpleOff` resets on `startDraft`. If a user re-opens a saved late draft, they lose the "stays full" choice. Carry it in the autosave record (additive, no engine change) so the door stays open.
4. **A "why this pick" one-liner in simple mode** reusing `planWhy`/`teamIdentity` — the simple form currently hides advice; a single sentence ("best DT left, fills your DT2 need") would keep the late rounds teachable without the math.
5. **Late-round flex pricing hint.** The flex chips are hidden in simple mode; a tiny "−10 to FS only" footer note (the existing QB→FS rule) would prevent a late-round mistake without re-introducing the chip clutter.
