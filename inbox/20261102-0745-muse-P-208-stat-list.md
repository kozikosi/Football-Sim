# V1 career stat list (locked: 10 stats)

## Ground rules (from the locked prompt + contract)

- **Trigger:** stats record once, at *elimination* (miss playoffs / lose in any round / win Super Bowl), flagged on the slot (`statsRecorded`). Abandoned-before-elimination and draft-never-become-season record nothing.
- **Scope:** global by overall AND by franchise (Owner: "record by overall and by team... best record with each franchise").
- **Filters:** every stat must be *earned* (no participation counters) and have a *display home* (profile panel section).
- **Source data:** the season envelope (final table, user's results, playoff results, champion, frozen roster) — no game logs.

## The ten stats

### 1. Super Bowl wins
- **Definition:** count of championships, with the team(s) won with.
- **Trigger:** elimination by winning the Super Bowl.
- **Display home:** profile header — "Super Bowls: 3 (KC ×2, DET ×1)".
- **Data:** champion == user team; franchise from frozen roster.

### 2. Undefeated seasons (20-0)
- **Definition:** seasons finishing 20-0 (17-0 regular + 3 playoff wins), with team and year.
- **Trigger:** Super Bowl win with zero losses (regular + postseason).
- **Display home:** profile header, shimmer treatment — the game's thesis stat.
- **Data:** final table (0 losses), playoff results (3-0).

### 3. Best playoff run (non-title)
- **Definition:** deepest round reached without winning it all, with team/year. Ranked: runner-up > conference championship loss > divisional loss > wild-card loss.
- **Trigger:** elimination in any playoff round.
- **Display home:** profile "Near misses" section.
- **Data:** playoff results, round reached.

### 4. Playoff appearances
- **Definition:** count of seasons reaching the playoffs, by franchise.
- **Trigger:** elimination after Week 18 with a playoff berth (any exit thereafter doesn't double-count — the flag guards it).
- **Display home:** profile "Postseason" section.
- **Data:** final table (playoff berth), franchise.

### 5. Best regular-season record
- **Definition:** best W-L in a single regular season, overall and per franchise. Ties keep the earliest.
- **Trigger:** elimination (miss playoffs or any playoff exit — the regular-season record is final at that point).
- **Display home:** profile "Best seasons" section.
- **Data:** final table W-L.

### 6. Longest win streak
- **Definition:** most consecutive wins within a single season (regular + playoffs combined), with team/year.
- **Trigger:** elimination (streak is final).
- **Display home:** profile "Best seasons" section.
- **Data:** user's game-by-game results (in the season envelope's results, not full logs — W/L sequence only).

### 7. First Super Bowl (per franchise)
- **Definition:** the first championship with each franchise: team + year. One row per franchise, filled once.
- **Trigger:** Super Bowl win with a franchise that has no recorded title.
- **Display home:** profile "Franchise firsts" section.
- **Data:** champion == user team; check existing titles for the franchise.

### 8. Draft steals
- **Definition:** count of drafted players (round 4+) who became season-long starters (started 10+ games), with the best example (name, round, OVR).
- **Trigger:** elimination (starter status is final at season end).
- **Display home:** profile "Drafting" section.
- **Data:** frozen roster + draft log (round picked) + games started (in season results, not logs).

### 9. Best draft class
- **Definition:** the draft class (year) with the most total starter-seasons from a single draft, with team/year.
- **Trigger:** elimination.
- **Display home:** profile "Drafting" section.
- **Data:** draft log + starter-seasons per player.

### 10. Franchise legend formula
- **Definition:** a single score per franchise: `titles × 100 + playoff_appearances × 10 + best_Wins` (best regular-season wins with that franchise). Ranks the user's franchises.
- **Trigger:** recomputed at every elimination (derived from stats 1, 4, 5 — no new data).
- **Display home:** profile "Franchise ranking" section — the leaderboard of the user's career.
- **Data:** derived; no new fields.

## Cut list (deliberately excluded)

- **Blowout wins / biggest margin:** vanity, no display home that isn't bragging without earning.
- **Total wins (career):** participation counter — rewards volume over excellence. (Per-franchise total record is kept as context for stat 10's inputs, not as a displayed stat.)
- **Fewest points allowed / most points scored (season):** subsumed by best record; no independent meaning in a sim.
- **Comeback wins:** requires play-by-play; logs are pruned.
- **Anything requiring game logs:** the Owner pruned them; the list respects that.
