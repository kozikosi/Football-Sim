## Source Requirement (Owner 25 Oct; OR item #2)

> "The 'change' button should align with overall color palette, not always blue."

---

## Current State Analysis

**No "Change" button exists** in current codebase. The draft setup panel has:
- Team selector: `#draftSlotSelect` (select)
- Pick selector: `#draftPickChip` (button "🎲 Random") + `#draftPickNumberSelect` (hidden select)
- Start button: `#startDraftBtn` (class `resetbtn`)

**Owner wants a "Change" button** that uses team palette colors (not hardcoded blue).

**Interpretation:** Add a "Change" button next to the selectors that resets/clears the team and pick selection, styled with team colors (`--team-primary`, `--team-secondary`).

### 3. JS Integration

**In `applyTeamColorsToUI(teamName)` function (from S-UK-15/S-UK-16):**

```javascript
function applyTeamColorsToUI(teamName) {
  const tc = TEAM_COLORS[teamName] || TEAM_COLORS_DEFAULT;
  const root = document.documentElement;
  root.style.setProperty('--team-primary', tc.primary);
  root.style.setProperty('--team-secondary', tc.secondary);
  root.style.setProperty('--team-accent', tc.accent || tc.secondary);
  root.dataset.team = teamName; // for CSS fallback
  
  // Update Change button immediately (CSS vars auto-update)
  // Update Start Draft button too
  const startBtn = document.getElementById('startDraftBtn');
  if (startBtn) {
    startBtn.style.background = `linear-gradient(120deg, ${tc.primary}, ${tc.secondary})`;
    startBtn.style.boxShadow = `0 4px 16px ${colorMix(tc.primary, 35%)}`;
  }
}

// colorMix helper
function colorMix(color, percent) {
  return `color-mix(in srgb, ${color} ${percent}%, transparent)`;
}
```

**Change button click handler:**

```javascript
// Reset team/pick selectors
document.getElementById('changeDraftBtn')?.addEventListener('click', () => {
  const teamSelect = document.getElementById('draftSlotSelect');
  const pickChip = document.getElementById('draftPickChip');
  const pickSelect = document.getElementById('draftPickNumberSelect');
  
  // Reset team to first option (or default)
  if (teamSelect) teamSelect.selectedIndex = 0;
  
  // Reset pick to Random
  if (pickChip) {
    pickChip.textContent = '🎲 Random';
    pickChip.style.display = 'inline-block';
  }
  if (pickSelect) {
    pickSelect.style.display = 'none';
    pickSelect.value = 'random';
  }
  
  // Update team colors to default
  const defaultTeam = teamSelect?.options[0]?.value || 'Kansas City Chiefs';
  applyTeamColorsToUI(defaultTeam);
  
  // Update start button display
  updateStartDraftDisplay(defaultTeam);
});
```
