NFL 2026 SEASON OT RULES (regular season per NFL Rulebook §9):

Regular Season:
- Game ends after the first quarter’s overtime: 10-minute periods (not sudden death), no coin toss, each team gets ONE OFFENSE POSESSION except:
- If first team scores a touchdown (any result: touchdown, 2-pt conv, FG): game ends immediately.
- If first team scores a safety: game ends immediately.
- If first team scores a field goal: second team gets a possession, game ends after that (no sudden death).
- If first team does not score (turnover, safety, touchback, etc.): second team gets a full possession.
- After second team’s possession: if tied, game ends; if second team scores, second team wins; if second team scores a touchdown, game ends; if second team scores a field goal, game ends; if second team scores a safety, game ends; if game still tied after second possession, game ends (no further OT).
- OT starts with kickoff, offensive formation cannot be bunched (normal snap from 7 yards deep).

Playoffs (NFL playoff rules, similar but different timing):
- 15-minute periods, continuous clock except for injuries/timeouts and the last two minutes of each quarter. Sudden death from the start: first team to score wins (no overtime beyond the first possession unless it’s a tie after a field goal).
- Both teams receive an initial possession (except when a touchdown ends game immediately).

Source: 2026 NFL Official Rulebook, Sections 1, 5, 9 (verified from NFL.com rules page).

FIELD GOALS IN OVERTIME (special rule):

- Regular season: no sudden death, field goals from either team end the game (no further scoring attempt). No OT beyond tied field-goal possessions.
- Playoffs: sudden death from start, field goals end the game for the scoring team (no further possessions).

SAFETIES IN OVERTIME (special rule):

- Both regular and playoff: safety ends the game immediately for the defensive team.

TIES IN OVERTIME:

- Regular season: ties allowed (any score after initial two possessions). No further OT after tied first/second possessions.
- Playoffs: sudden death; ties go to multiple 15-minute periods until a winner.

Points per overtime (league-average 2020-2025):

- Points scored: ~6.5 per OT per game (avg across both teams)
- Field goals: ~1.9 per OT per game
- Touchdowns + PAT/2-pt: ~4.6 per OT per game

Source: 2020-2025 league scoring data, aggregated from NFL.com stats pages.
