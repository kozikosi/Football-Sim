The slot inventory is useful, but the proposal calls FB and P draft/lineup slots when the pinned build treats them only as ranking metadata. That difference blocks both the proposed math and the related 28-round draft work.

- **Defect (shown): P and FB are not roster or draft slots in Pre-Colors.** `ROSTER_SLOTS` contains exactly 26 entries, includes K, and excludes P and FB; the adjacent `TOTAL_ROUNDS` comment explicitly says “no … P/FB.” `NATURAL_SLOT_MAP` and `SLOT_FAMILY` also do not define either position, while `POS_SLOT_MAP` is derived from `NATURAL_SLOT_MAP`. `cpuPick()` loops only eligible `POS_SLOT_MAP` slots, so the existing comment that rounds 1–3 constrain kicker/punter/fullback picks does not make P/FB draftable. The proposal's statements that FB/P have lineup slots, can be missing from `TEAM_DATA`, and are filled with 70 OVR are not supported by this build.
- **Defect (shown): listing P/FB in `GROUPS`, `GROUP_DEFS`, weights, and `POSITION_TIER` does not wire them into game value.** The current `RATING_SPECS`/`DEF_SPECS` and `teamRatings()` contain no FB run-blocking share or punter rating/term; `slotWinsTable()` iterates only `ROSTER_SLOTS`. `groupAvgFromPool()` and `groupAvgForTeam()` produce position-group rankings from player pools, not the simulated lineup's game ratings. Therefore changing the group averages or showing a specialist weight would not implement the proposed FB/P effect in the game engine. Treat draft-slot support, ranking display, and game-value math as distinct integration points.
- **Risk (likely): the suggested “active/inactive slots” shortcut cannot be applied as written.** The current average helpers select top players from a pool by position and fixed `def.n`; they do not consume lineup slots or an active-slot flag. The actual engine instead builds ratings from `slotmap` and fixed `RATING_SPECS`. A future 3-4 proposal must name which data path each affected output uses, rather than describing one flag as updating both sets of calculations.
- **Calibration question:** P-032 depends on a product choice about new drafted roster spots and math, while P-141 asks to review the 28-round draft and correct documents. The pinned build currently has 26 rounds.
