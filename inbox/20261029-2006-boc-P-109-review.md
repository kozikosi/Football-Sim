## Defects found (new, beyond vl/beam)

1. **`renderKeyPlayersHTML` emits the function object, not the cards.** In the work snippet, `card()` ends with
   `return \`<div class="kp-column ...">${card}\`;`
   `${card}` coerces the inner function to its source string — the column renders the function text, not the player cards. Must be `${players}` (the already-computed joined string). **Definite bug; missed by both prior reviews.**

2. **Missing closing `</div>` for `kp-column`.** Should be `${players}</div>`.

3. **`kp-slot` uses `LABELS[p.group]`** but `p.group` is a position group (`QB`, `RB`, `WR`, `TE`, `DL`, `LB`, `DB`), not a slot, so `LABELS[...]` is `undefined` and falls through to the group name anyway. Drop the `LABELS` lookup; use `p.group` directly (matches the original "pos" column). Cleaner and avoids implying a slot map entry that does not exist.

4. **`renderPreviewPanel` is not actually changed** despite integration point #4. The snippet leaves `renderPreviewPanel` calling `starsFaceoffHTML(g)` then `g.preview`; `renderKeyPlayersHTML` is invoked separately in `renderGameResultHTML`. If "lineups directly below" the stars is required, the Architect must either embed `renderKeyPlayersHTML` into `renderPreviewPanel` or reorder the calls in `renderGameResultHTML`. Flagging as an open structural decision, not a code bug.

5. **`stars-faceoff` label says "KEY PLAYERS"** while the section below says "GAME BALL & KEY PLAYERS" — duplicate label. Recommend restoring the original "STARS (85+ OVR)" wording to distinguish the two sections.

6. **Reduced-motion block only stops `.star-card`/`.kp-card` float**, not the `.shimmer` animation nor the light-mode overrides. Add `animation: none` for all `.shimmer` under `prefers-reduced-motion`.

7. **`getTeamColor` fallback is `#4f8cff` (blue)** which the Owner explicitly bans as a neutral ("neutral = white; no blue panels"). Change fallback to `var(--gold)` (or white in light mode). Also the hardcoded 32-team map duplicates P-004 and its values are unverified against the Owner's 22 Oct table — verify row-by-row before shipping (data-integrity rule, AGENTS.md §7).

8. **Avatar text colour `#0d0a0e`** on a `getTeamColor` background: low contrast for light team colours (e.g. Saints `#D3BC8D`). Note for the Architect; not blocking.

9. **`kp-ovr.vibrant` fallback is `var(--accent)` (blue)**; change to `var(--team-primary, var(--gold))` to match team colour and avoid permanent blue.

10. **`star-85` CSS uses `var(--accent)` (blue)** in the snippet; change to `var(--team-primary, var(--gold))` (vl already flagged; restating for the final corrected CSS).

11. **Shimmer gradients use `#fff`** (4 places) — violates the no-white-text rule; use `var(--text)` (beam already flagged).

12. **`grade.toFixed(1)`** — prior reviews want `Math.round(grade)` per P-183 integers-only. I agree for consistency with P-183, but note unit grades are averages (original code uses `.toFixed(1)`). Architect's call; I recommend `Math.round` and a note that if grades are treated as averages, one decimal is defensible. (Not re-litigating further.)

13. **No mobile overrides** for `.stars-grid` / `.identity-bars` (`.kp-grid` already has one at l.153). Add `@media (max-width:760px)` stacking.

14. **`textShimmer` keyframes absent** from Pre-Colors — either add locally (risking duplication with P-077/P-101) or declare the dependency. I recommend adding locally with a `/* TODO: dedupe with P-077/P-101 */` comment, so the snippet is self-contained.

15. **`Cinzel Decorative` not loaded** — use `var(--display-font, serif)` (or plain `serif`) until P-183 lands, to avoid a missing-font fallback.

16. **Hover `transform` conflicts with the float animation** (both set `transform`); minor — the float pauses on hover. Acceptable; noting only.

function renderKeyPlayersHTML(g){
  const mvp = g.detail.mvp;
  function card(team, sd){
    const players = notablePlayers(sd).map(p=>{
      const star = p.name===mvp.name && p.team===mvp.team;
      const isUser = team === seasonUserTeam();
      return `
        <div class="kp-card ${star ? 'kp-mvp' : ''}" style="${isUser ? 'border-color:var(--team-primary, var(--gold));' : ''}">
          <div class="kp-avatar" style="background:${getTeamColor(team)}">${p.name.charAt(0)}</div>
          <div class="kp-info">
            <div class="kp-name ${star ? 'shimmer' : ''}">${p.name}${star ? ' <span class="game-ball">★</span>' : ''}</div>
            <div class="kp-slot">${p.group}</div>
            <div class="kp-stats">${p.line.replace(/, /g,' · ')}</div>
          </div>
          <div class="kp-ovr ${p.ovr>=90 ? 'shimmer' : (p.ovr>=85 ? 'vibrant' : '')}">${p.ovr}</div>
        </div>
      `;
    }).join('');
    const isUser = team === seasonUserTeam();
    return `<div class="kp-column ${isUser ? 'user' : ''}">${players}</div>`;
  }
  return `
    <div class="key-players-below">
      <h4 class="kp-label">GAME BALL & KEY PLAYERS</h4>
      <div class="kp-grid">${card(g.away, g.detail.away)}${card(g.home, g.detail.home)}</div>
    </div>
  `;
}
```

function renderIdentityPanel(team, title, open, isUser){
  const S = seasonState, rt = S.unitRatings[team], rk = S.unitRanks[team];
  const rows = Object.keys(UNIT_INFO).map(u=>{
    const r = rk[u], grade = rt[u];
    const pct = Math.max(0, (33 - r) / 32 * 100);
    const barColor = r<=8 ? 'var(--gold)' : r>=25 ? 'var(--bad)' : 'var(--accent)';
    return `
      <div class="identity-row">
        <span class="identity-label">${UNIT_INFO[u].label}</span>
        <div class="identity-bar-track">
          <div class="identity-bar-fill" style="width:${pct}%; background:${barColor};"></div>
        </div>
        <span class="identity-rank ${r<=8?'top':r>=25?'bottom':''}">#${r}</span>
        <span class="identity-grade">${Math.round(grade)}</span>
      </div>
    `;
  }).join('');
  const paras = identityParagraphs(team, isUser).map(t=>`<p class="detail-item">${t}</p>`).join('');
  return `<details class="panel" style="margin-bottom:14px;" ${open?'open':''}><summary style="cursor:pointer;font-weight:700;">${title} <span class="narr" style="font-weight:400;">(${team})</span></summary>
    <div style="margin-top:8px;">${paras}</div>
    <div class="identity-bars">${rows}</div></details>`;
}
```
