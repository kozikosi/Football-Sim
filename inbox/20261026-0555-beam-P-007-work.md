## Exact integration
```javascript
// In simulateCurrentWeek, replace the user-game call:
const isUserGame = g.home === seasonUserTeam() || g.away === seasonUserTeam();
if (isUserGame && !window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
  animateGame(g, isPlayoff); // async; returns promise

}
```
`animateGame(g, isPlayoff)`:
1. Call `simulateGame` + `gameFlow` + `buildGameDetail` up front (so result is ready), but delay DOM updates.
2. Render initial empty scoreboard + centre "KICKOFF".
3. Walk `g.result.homeEvents`/`awayEvents` sorted by q,t; for each, after a scheduled delay, append a play line, update score, flash on turnover/TD.
4. At quarter boundaries, show end-of-quarter flash.
5. At final, show "FINAL" graphic + score line + shimmering verdict; hide Skip; wait for CONTINUE click.
