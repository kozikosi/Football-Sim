## Where drives.ts assumes a flat rate (VERIFIED)

`colors/src/engine/drives.ts`:
- Line 169 (regulation): `for (const s of ['home','away']) for (let i = 0; i < comp[s].fg; i++) if (chance(rD, 0.176)) mfDraw[s]++;` — each planned FG (from `decompose`) has a 17.6% chance of becoming an extra missed-FG drive. Implied make rate = 1/(1+0.176) = 85.0%, distance-independent. Consistent with measured 85.17% overall, but ignores distance.
- Line 222-225 (overtime): `pFG = clamp(0.2 * Math.sqrt(r), 0.08, 0.3)` then `end = chance(rO, 0.87) ? 'FG' : 'FG_MISS'` — a second, different flat rate (87%). Inconsistent with regulation (85.0%) and measured (85.17%), within ~2 points.

`colors/src/engine/kicking.ts` CURVE (labelled INFERRED in source) compared to measured band make %: slightly optimistic at 40-45 yd (0.89 vs 0.83; 0.82 vs 0.76), roughly right elsewhere. CURVE feeds `leagueMakeProb()` and `inSeasonKickerRating()`, not the drive model directly.

## Proposed changes (INFERRED, for the Architect's verdict)

1. Add `getFGMakeRate(dist)` to `colors/src/engine/kicking.ts` (or a new helper), returning the measured band make % for a given distance. Proposed lookup by 5-yd band (matches the data resolution):
   ```ts
   // measured: nflverse pbp 2020-2025, 6,609 attempts
   const FG_MAKE_BY_BAND: [number, number][] = [
     [19, 0.990], [24, 0.990], [29, 0.969], [34, 0.963],
     [39, 0.907], [44, 0.834], [49, 0.762], [54, 0.733],
     [59, 0.624], [64, 0.426], [69, 0.312], [74, 0.000],
   ];
   export function getFGMakeRate(dist: number): number {
     for (const [hi, p] of FG_MAKE_BY_BAND) if (dist <= hi) return p;
     return 0.0;
   }
   ```
   Values are the measured 5-yd-band make percentages at the band's upper bound.

2. Refine `kicking.ts` CURVE breakpoints to the measured values:
   `[18, 0.995], [30, 0.96], [40, 0.83], [45, 0.76], [50, 0.73], [55, 0.62], [60, 0.43], [65, 0.31], [70, 0.12]`
   (70+ kept conservative; n=2 in the 70-74 band.)

3. Align the two flat rates: set OT `chance(rO, 0.87)` to `chance(rO, 0.85)` (matching regulation's implied 85.0% and measured 85.17%), or make OT distance-aware:
   ```ts
   const fgDist = drawFgDistance(rO);   // from measured attempt distribution
   end = rO.next() < getFGMakeRate(fgDist) ? 'FG' : 'FG_MISS';
   ```
   OT drives are single-drive outcomes not tied to a pre-decomposed score, so this is safe there.

4. Distance draw helper (for OT and, later, regulation stats), from the measured attempt distribution:
   ```ts
   function drawFgDistance(rng: Rng): number {
     const u = rng.next();
     const bands = [[18,29,0.219],[30,39,0.281],[40,49,0.285],[50,59,0.200],[60,74,0.012]];
     let acc = 0;
     for (const [lo, hi, w] of bands) { acc += w; if (u < acc) return lo + Math.floor(rng.next() * (hi - lo + 1)); }
     return 39;
   }
   ```
   (The <18 and 15-19 share is folded into the 18-29 band; total share ~1.0.)

5. Regulation: makes are fixed by `decompose()` (c.b field goals = 3 pts each), so the make count cannot be randomized without changing the score. Keep the 0.176 miss draw (already matches 85% overall). Optionally assign a distance to each FG/FG_MISS drive for recap and in-season kicker rating, without changing scores. Larger change (Drive gains `fgDist`); deferred.
