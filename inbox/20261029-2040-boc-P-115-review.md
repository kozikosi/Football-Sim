## New findings (beyond reviews #1/#2)

### F1 — Turnover hook is wrong (the big one)
UK's spec sources turnovers from `g.result.homeEvents`/`awayEvents` with `type:'TO'`. But:
- `homeEvents`/`awayEvents` contain only TD/FG/SAF/OTH scoring events (makeScoringEvents, l.2729–2740). No turnovers.
- Turnovers live in `g.detail.home.giveaways` / `g.detail.away.giveaways` as `{type:'INT'|'FUM', q, name, group, team}` (l.2529–2533).
So the animation must source turnovers from `g.detail[side].giveaways`, not from scoring events. The giveaway objects lack a `t` (time within quarter) for ordering — add `t: Math.random()` when building, or sort by q then index.

Also, `g.detail` is only built in `playGame` (l.3481), so the animation (which runs for the user's game only) has access. Good.

### F2 — OT timing exceeds Owner's 60s cap
UK states "Max (OT thriller): ~75s" but the Owner's P-007 answer caps at 30-60s. Either cap OT games at 60s (skip some plays) or document the discrepancy and let the Architect decide. I recommend capping at 60s with a note.

### F3 — `var(--team-primary)`/`var(--opp-primary)` absent (P-004)
Guard with `var(--team-primary, var(--gold))` / `var(--opp-primary, var(--accent))`. (Beam caught; re-stating.)

### F4 — `Cinzel Decorative` absent (P-111/P-183)
Guard with system font stack until P-183 lands.

### F5 — CONTINUE button appended to `document.body`
UK's `showFinalVerdict` does `document.body.appendChild(continueBtn)`. Appending to body places it outside the animation container and it may persist after the animation closes. Fix: append to the animation container (`#animCentre`'s parent) and remove (not just hide) it on click. (Beam caught the "removed after click" need.)

### F6 — `+x` score-pop needs a positioning context
`.score-pop` is `position: absolute`; its parent must be `position: relative`. Ensure the live-score container is the positioning context, otherwise the pop floats relative to the nearest positioned ancestor (possibly the whole page).

### F7 — Giveaway `q` but no `t`
Giveaways have `q` (quarter) but no within-quarter time. For animation ordering within a quarter, sort by q then by array index (or add `t`). Recommend adding `t` at generation time for consistency with scoring events.

### F8 — "Skip disappears at the end" vs "Skip → CONTINUE"
UK says Skip disappears and is replaced by CONTINUE. Make sure the Skip button is removed from the DOM (not just `display:none`) so it can't be re-triggered, and CONTINUE is the only action. (Minor.)

### F9 — `animateGame` dependency
`animateGame` does not exist yet (P-007 adds it). The spec is correct to say "Add to P-007 spec", but the implementation section should note that `animateGame` is created by P-007 and that P-115's refinements are folded into it. No code changes to Pre-Colors.

### F10 — `playGame` line ref
UK says l.3479; actual l.3478. Minor.

Turnovers are NOT in `homeEvents`/`awayEvents`. Source them from the game detail:

```javascript
// In animateGame (created by P-007), after playGame(g) has run:
const turnovers = [
  ...g.detail.home.giveaways.map(x => ({...x, side: 'home'})),
  ...g.detail.away.giveaways.map(x => ({...x, side: 'away'}))
].sort((a,b) => a.q - b.q || (a.t||0) - (b.t||0));

// Each turnover event:
```
