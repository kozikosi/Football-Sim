## Findings

### 1. QB rushing: two formulas give different results
uk proposes two different QB rush EPA formulas:
- **Formula A** (recommended value section): `base (0.12 designed / 0.85 scramble) + (qbOVR - 70) * 0.005`
  - QB 90 OVR: 0.12 + (20 × 0.005) = 0.22 EPA/designed rush
- **Formula B** (alternative): `0.15 + (qbOVR - 70) * 0.005`
  - QB 90 OVR: 0.15 + (20 × 0.005) = 0.25 EPA/designed rush
The base values differ (0.12 vs 0.15) and the recommended per-OVR value (0.025) doesn't match the code (0.005). Three inconsistencies:
- 0.025 is the "recommended" per-OVR value but the code uses 0.005.
- 0.12 (PFF Jackson) vs 0.15 (alternative base) — which is correct?
- The recommended value (0.025) × 100 rush attempts = 2.5 EPA/season per OVR point, but the calibration says 0.5-1.0 EPA/season per OVR point. Factor of 2.5-5x discrepancy.

### 2. WR blocking: table values don't match the formula
uk's table:
| Grade | EPA per run play |
| 80 | +0.08 |
| 70 | +0.05 |
| 60 | +0.02 |
| 50 | 0.00 |

But the formula `WR_BLOCK_VALUE_PER_OVR = 0.002` gives:
- 80 OVR: (80-50) × 0.002 = +0.06 (not +0.08)
- 70 OVR: (70-50) × 0.002 = +0.04 (not +0.05)
- 60 OVR: (60-50) × 0.002 = +0.02 (matches)
- 50 OVR: 0 (matches)

The table and formula disagree by 33-50% at the top end. The `wrBlockEPA` function uses `(wrCorpsAvgOVR - 70) * 0.002` with baseline 70, while the table uses baseline 50. Two different baselines in the same proposal.

### 3. `runGameEPA` alternative uses yet another formula
`runGameEPA += (avgWRBlockGrade - 50) * 0.006` — with grade 80: (30) × 0.006 = 0.18. But the table says 80 → +0.08. Factor of 2.25x. Three different WR blocking formulas in one proposal, none agreeing.

### 4. "0.54 EPA swing per negatively graded block" overstates
The PFF "perfectly blocked" study shows:
- 0 negative blocks: +0.27 EPA/play (34.9% of plays)
- 1+ negative blocks: -0.27 EPA/play (65.1% of plays)
The 0.54 EPA swing is between two PLAY CATEGORIES (clean vs. dirty), not per individual block. A play with 2 negative blocks isn't necessarily 2× worse. The claim "0.54 EPA swing per negatively graded block" misattributes a play-level difference to a per-block value.

### 5. QB rushing calibration math has unit confusion
The calibration says:
- "Rush EPA difference per season ≈ 15-25 EPA (rushing QBs vs non-rushing)"
- "OVR spread ≈ 25-30 points (60 → 90)"
- "ΔEPA per OVR point for rushing ≈ 0.5-1.0 EPA/season per OVR point"

But 15-25 EPA / 25-30 points = 0.5-1.0. OK, that's consistent. However, the recommended per-rush value (0.025) × 100 rushes = 2.5 EPA/season per OVR point, which is 2.5-5x the calibrated 0.5-1.0. The per-rush and per-season values are inconsistent.

### 6. "Points per win" numbers don't reconcile
- bignokh.com: "~99.5 EPA = 1 QB win above replacement" (QB-specific)
- nflWAR table: "Points per win (β_S reciprocal) ~30-35 EPA" (team-level)
- 99.5 EPA/win (QB) vs 30-35 EPA/win (team) — these are different metrics. The QB value should be derived from the team value: 30-35 EPA/team-win × 0.675 QB share = 20-24 EPA/QB-win. But bignokh says 99.5. The table's rough calculation "218.83 team EPA/win × 0.675 QB share / 4.1 wins?" doesn't produce 99.5 or 30-35. The math is unclear.

### 7. QB rushing value is from a single player (Lamar Jackson)
The PFF values (0.12 designed, 0.85 scramble) are from Lamar Jackson specifically. Jackson is an outlier (most rushing QBs have lower scramble EPA). Using Jackson as the baseline overestimates QB rushing value for average rushing QBs. Recommend: cite a population average or at least note the outlier bias.

### 8. WR block grade data is from one season (2022)
The Pro Football Techs data is 2022 only. WR blocking grades vary significantly by season (coaching scheme, opponent quality). Recommend: note the single-season limitation or cite multi-season data.

### 9. Code uses different constants than recommended
- QB: recommended 0.025, code uses 0.005 (5x difference)
- WR: recommended 0.002, but table implies 0.0027 (0.08/30), and `runGameEPA` uses 0.006 (3x the table)
The Architect cannot implement this as written — the numbers contradict each other.

### 10. Missing: how to handle QBs who don't rush
The formulas assume all QBs rush. Non-rushing QBs (e.g., pocket passers) would get negative or zero rushing EPA with these formulas. The drive model needs a floor or a "non-rusher" branch.

## Verdict summary
uk's evidence gathering is thorough (9 sources cited, specific PFF grades, nflWAR paper). But the calibration math has multiple internal inconsistencies:
- Three different QB rush formulas that don't agree.
- Three different WR blocking formulas that don't agree.
- Recommended values don't match the code.
- "0.54 EPA per block" overstates a play-level difference.
- Single-player/single-season data presented as population values.

RECOMMEND: improved (keep the source citations, fix the 10 calibration inconsistencies before the Architect uses these numbers).
