## Independent verification of VL's P-200 offensive personnel calibration

I reviewed VL's P-200 work file and beam's P-200 review, and provide this third-party assessment of the offensive personnel calibration proposal.

## VL's work: strengths and innovations

### Good foundations

1. **Engaged with spec §14.3** - VL correctly references the "uncalibrated experiment" from the spec, understanding that '10' personnel was tested with cost 0.22 and resulted in TE1 value erosion (-32%).

2. **Quantifies the problem** - VL accurately states that to preserve TE1 value (0.686 wins) and match measured 10-personnel share (0.52%), cost needs to rise from 0.22 to ~0.55.

3. **Speculates reasonable extensions** - VL proposes 13-personnel as a selectable plan, which aligns with the spec's mention of 10 and 13 in the title.

4. **Identifies design challenges** - VL correctly identifies that TE3 as the fourth TE slot needs special handling rather than using the generic 70 value.

5. **Provides specific implementation** - VL gives concrete JavaScript snippets for the personnel sets.

### Issues with VL's approach

1. **Invented weights for 11/12/13** - VL provides specific weights for '11', '12', and '13' personnel sets that are not from the spec or any measured data. The spec only documents the '10' experiment. These invented weights create uncertainty for Architect integration.

2. **Unverified cost assumptions** - VL assumes cost = 0 for '11', '12', and '13', and cost = 0.55 for '10'. The spec explicitly states the cost is INFERRED and cannot be pinned from data alone. VL should present these as calibration targets, not calibrated values.

3. **TE3-aware blocking term changes spec** - VL proposes changing `(te2+70)/2` to `(te2+te3)/2`, which conflicts with spec §14.6d that explicitly says "still uses a generic 70 for TE3 (not changed); integrate the design whenever the 13-personnel slot is actually used."

4. **Missing verification procedures** - VL does not specify the exact command or verification steps needed to calibrate the cost from 0.22 to 0.55 while preserving TE1 value.

5. **Unclear about 13-personnel selectability** - The spec mentions 10 and 13 in the title but VL does not clearly address whether 13 should actually be a selectable plan given that TE3 has zero plan value according to the spec.
