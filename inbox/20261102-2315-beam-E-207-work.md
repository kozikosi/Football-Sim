## Head-to-head history: spec for Colors v1

### What it does
When two teams meet in a game (regular season or playoffs), check if they have played before this season. If so, mention the prior result briefly: "Colts won 24-20 in Week 3." Division-rematch labels must count real prior meetings, not assume "second meeting."

### Data source
`SeasonResult.games` — an array of completed games with: homeTeam, awayTeam, homeScore, awayScore, week, isPlayoff.

### Function spec

```js
// Pure function: given a list of completed games and two team IDs,
// return the prior meeting(s) between them this season.
function priorMeetings(games, teamA, teamB) {
  return games.filter(g =>
    (g.homeTeam === teamA && g.awayTeam === teamB) ||
    (g.homeTeam === teamB && g.awayTeam === teamA)
  ).map(g => ({
    week: g.week,
    isPlayoff: g.isPlayoff,
    winner: g.homeScore > g.awayScore ? g.homeTeam : g.awayTeam,
    score: `${Math.max(g.homeScore, g.awayScore)}-${Math.min(g.homeScore, g.awayScore)}`,
    homeTeam: g.homeTeam,
  }));
}
```

### Wording rules
- 0 prior meetings: no mention.
- 1 prior meeting: "Colts won 24-20 in Week 3" (regular) or "Colts won 24-20 in the Wild Card round" (playoff).
- 2+ prior meetings: "Colts won 24-20 in Week 3; Titans won 17-14 in Week 11."
- Playoff rematch after regular season: "Colts won 24-20 in Week 3; this is their second meeting."
- Never say "second meeting" unless there was exactly one prior meeting.

### Division-rematch bug fix
The old code assumed division rivals always play twice (Week X and Week Y). The fix: count actual prior meetings in SeasonResult.games. If they haven't played yet (e.g., Week 2), don't say "second meeting."
