## CONFIRMED DEFECTS (from prior reviews + new)

### CRITICAL (would break rendering)

1. **Missing `</div>` for `kp-column`** (work line 108)
   - `return \`<div class="kp-column ...">\${card}\`;` — never closes the div
   - **CONFIRMED** by vl, boc — HTML parsing would break

2. **`\${card}` emits function source, not player cards** (work line 108)
   - `card` is a function; template literal coercion produces function source code
   - Should be `\${players}` (the joined string from line 106)
   - **CONFIRMED** by boc — "definite bug; missed by both prior reviews"

3. **`textShimmer` keyframes don't exist in Pre-Colors**
   - Used in 5 CSS rules (`.star-name.shimmer`, `.star-ovr.shimmer`, `.kp-name.shimmer`, `.kp-ovr.shimmer`, light-mode override)
   - **CONFIRMED** by vl, beam — depends on P-077/P-101/P-058

4. **`Cinzel Decorative` font not loaded**
   - Used in `.star-ovr`, `.kp-ovr`, `.identity-grade`
   - **CONFIRMED** by vl, boc — depends on P-183

### HIGH (visual/logic errors)

5. **`grade.toFixed(1)` violates "integers only" (P-183)**
   - Line 138: `\${grade.toFixed(1)}` → e.g., "78.5"
   - Should be `Math.round(grade)`
   - **CONFIRMED** by vl, beam, boc

6. **`star-85` uses `var(--accent)` (blue) instead of team color**
   - Line 177: `.star-card.star-85 { border-color: var(--accent); }`
   - Owner wants 85+ players "more vibrant in their color"
   - **CONFIRMED** by vl, boc

7. **`getTeamColor` / `TEAM_PRIMARY_COLORS` duplicate P-004 data**
   - Work lines 310-323 embed 32-team table with `#4f8cff` fallback (blue)
   - Owner bans blue as neutral ("neutral = white; no blue panels")
   - **CONFIRMED** by vl, boc

8. **`notablePlayers` doesn't set `p.team`**
   - `renderKeyPlayersHTML` line 93 checks `p.team===mvp.team`
   - `notablePlayers(side)` returns players from `side.players` without `team` property
   - **CONFIRMED** by vl — MVP star detection may never match

9. **Shimmer gradients use `#fff` (4 places) — violates no-white-text rule**
   - Lines 192, 202, 242, 252: `linear-gradient(90deg, var(--gold), #fff, var(--gold))`
   - **CONFIRMED** by beam, boc — replace with `var(--text)`

10. **`kp-ovr.vibrant` fallback is `var(--accent)` (blue)**
    - Line 257: `.kp-ovr.vibrant { color: var(--team-primary, var(--accent)); }`
    - Should be `var(--team-primary, var(--gold))`
    - **CONFIRMED** by boc

11. **No mobile CSS for 390px**
    - `.stars-grid`, `.kp-grid`, `.identity-bars` need `@media (max-width: 760px)` stacking
    - **CONFIRMED** by vl, boc

12. **`renderIdentityPanel` replacement loses `<thead>` structure**
    - Current has `<table><thead>...</thead><tbody>...</tbody></table>`
    - Proposal replaces with `<div class="identity-bars">` — header dropped
    - **CONFIRMED** by vl — acceptable for redesign but needs verification

13. **`renderPreviewPanel` untouched** (integration gap)
    - Work line 5405 not modified; "lineups directly below stars" requires embedding `renderKeyPlayersHTML` into `renderPreviewPanel` or reordering in `renderGameResultHTML`
    - **CONFIRMED** by boc — open structural decision

### MEDIUM

14. **Avatar text color `#0d0a0e` on light team backgrounds** (e.g., Saints `#D3BC8D`)
    - Low contrast for light primary colors
    - **NOTED** by boc — Architect decision

15. **Hover `transform` conflicts with float animation**
    - Both set `transform`; float pauses on hover
    - **NOTED** by boc — acceptable

16. **Reduced-motion block incomplete**
    - Only stops `.star-card`/`.kp-card` float, not `.shimmer` animations
    - **CONFIRMED** by boc
