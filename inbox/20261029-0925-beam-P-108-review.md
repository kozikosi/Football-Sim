## Additional findings vs review #1 (vl)

1. **CSS variable scoping bug.** `.victory-bar` gets `--home-color`/`--away-color` via inline style, but `.unit-bar.favor-home`/`.favor-away` and `.unit-value.home`/`.away` reference `var(--home-color)`/`var(--away-color)` from inside `.unit-edges`, which is a sibling of `.victory-bar`, not a child. CSS variables do not inherit across siblings. Fix: define `--home-color`/`--away-color` on the common ancestor `.matchup-math-graphical` (or `.panel`), or use fallbacks `var(--team-primary,var(--gold,#ffc43c))` / `var(--opp-primary,var(--accent,#4f8cff))` directly in each rule.

2. **Team names clipped.** `.victory-bar` has `overflow: hidden` but `.victory-teams` sits at `bottom: -24px`, outside the bar. The names will be clipped. Either remove `overflow: hidden`, add `padding-bottom: 28px` to the bar, or move team names inside the bar at `bottom: 4px`.

3. **Skew not un-skewed on team names.** `.victory-track` and `.victory-labels` handle skew/un-skew, but `.victory-teams` has no `transform: skewX(calc(var(--skew)*-1))`, so team names render skewed. Add the un-skew.

4. **`wpFrom` vs custom logistic.** The proposal's `homeWinProb = 1/(1+Math.exp(-spread/4.5))` diverges from the model's actual `wpFrom(mh, ma, HOME_FIELD)` at l.2181. Use `wpFrom(mh, ma, HOME_FIELD)` for the fill widths so the bar matches the model's win probability. Keep the parallelogram skew based on `spread` (or `projH-projA`).

5. **Unit-grade diff scale.** `pct = Math.min(Math.abs(diff)/30*100, 100)` with unit grades ~0-100 and diff rarely reaching 30. A diff of 5 (typical) gives 16.7% width, nearly invisible. Use a tighter scale (e.g., `/10*100` capped at 100) or scale by the max diff in the game. Pick one and document.

6. **`renderGameResultHTML` lacks exact old→new.** vl noted the anchor (l.3780) and that the proposal gives no exact replacement. The post-game view calls `matchupMathInner` indirectly? Actually `renderGameResultHTML` (l.3780) does not call matchupMathInner per grep. Confirm whether post-game should also show the new graphical math or keep the old table; if yes, provide exact old→new.

7. **`--gold` fallback.** `.pts-diff.pos { color: var(--gold); }` should be `var(--gold,#ffc43c)` for safety (already done elsewhere). Minor.

8. **`--opp-primary`/`--team-primary` deps.** Already noted by vl; restate: until P-004 lands, victory bar uses fallback colors, so team-specific theming won't show. Acceptable with fallbacks.
