## Win-probability graph spec

### What it shows
A line chart of win probability over game time (quarter by quarter, or play by play). The user's team's win probability is plotted as a line; the opponent's is the complement. Key moments (turnovers, TDs, FGs) are marked on the line.

### Data source
The game simulation already produces scoring events with timestamps (quarter, time). Win probability can be derived from the score differential and time remaining using a standard NFL win-probability model (e.g., based on score differential and time, not team strength).

### Implementation notes
- Use a simple SVG or canvas line chart (no library, one HTML file constraint).
- X-axis: game time (0-60 minutes, Q1-Q4). Y-axis: win probability (0-100%).
- Mark turnovers with a red dot, TDs with a green dot, FGs with a blue dot.
- The user's team's line is in team colour; opponent's in grey.
- Show the final win probability as a large number at the end.
- Responsive: chart shrinks to 390px width on mobile.

### Open questions
- Should it show play-by-play or quarter-by-quarter? Play-by-play is more dramatic but requires per-play data (the sim generates scoring events, not every play).
- Should it include a "swing" indicator (biggest win-probability change)?
- Should it be in the game review or the season review?

### Size estimate
Small (INFERRED): ~200 lines of JS + ~50 lines of CSS. No new data structures needed.
