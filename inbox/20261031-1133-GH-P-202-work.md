3. **REV 2 has one two-hop cheaper-than-direct path.** A direct-edge-only check gives `ILB→OLB→EDGE = 0 + 4 = 4`, versus direct `ILB→EDGE = 6`. This violates the proposed transitive-arbitrage invariant. This is a finding, not authorization to change protected `FLEX` values.

   A reproducible check for explicit legal edges (excluding the emergency fallback) is:

   ```js
   const violations = [];
   for (const [a, fromA] of Object.entries(flex)) {
     for (const [b, ab] of Object.entries(fromA)) {
       for (const [c, bc] of Object.entries(flex[b] || {})) {
         const direct = fromA[c];
         if (a !== b && b !== c && a !== c && direct != null && ab + bc < direct) {
           violations.push(`${a}->${b}->${c}: ${ab}+${bc}<${direct}`);
         }
       }
     }
   }
   ```

4. **Reachability is not currently gated.** `flexengine.js` checks that each dataset tag has a natural slot, but not that each tag has an explicit non-natural flex slot or that each slot is reachable. `flexcheck.mjs` has a “reachability” comment but no reachability assertion; its `FLEXCHECK OK` only means its shape/value checks passed, despite printing table differences from Pre-Colors. Suggested checks against explicit guide edges:

   ```js
   const roleOf = tag => TAG_ROLE[tag];
   const hasFlex = tag => SLOTS.some(slot =>
     !compiled.NATURAL[tag].includes(slot) &&
     (G[roleOf(tag)] || {})[SLOT_DEST[slot]] != null
   );
   const tagsWithoutFlex = Object.keys(TAG_ROLE).filter(tag => !hasFlex(tag));
   const unreachableSlots = SLOTS.filter(slot =>
     !Object.keys(TAG_ROLE).some(tag =>
       compiled.NATURAL[tag].includes(slot) ||
       (G[roleOf(tag)] || {})[SLOT_DEST[slot]] != null
     )
   );
   tagsWithoutFlex.forEach(tag => problems.push(`${tag}: no explicit flex slot`));
   unreachableSlots.forEach(slot => problems.push(`${slot}: unreachable`));
   ```
