--- DESIGN PROPOSAL ---

Concept: A line graph showing win probability over the course of a game, from kickoff (50%) to final whistle. Each play updates the probability. Key moments (TDs, turnovers) are marked with dots.

Data source: The game sim already computes expected points and win probability per play (via matchupModel + gameFlow). The play-by-play log (playByPlay) has per-play data. We need to extract per-play win probability and plot it.

Visual design:
- X-axis: play number (or game time: Q1-Q4).
- Y-axis: win probability (0-100%).
- Line: smooth curve, team colour (KC red). Opponent's perspective is 100 - WP.
- Key moments: TDs (gold dots), turnovers (red dots), lead changes (vertical dashed lines).
- Hover: tooltip showing play description + WP change.
- Final: WP at 100% (win) or 0% (loss).

Where to show:
- Game recap: below the score boxes, above the scoring log. Collapsed by default ("Show win probability graph").
- Game preview: optional "projected win probability" curve based on pre-game ratings (static, no play data).

Implementation:
- SVG-based (no canvas, no CDN). Inline SVG with polyline + circles.
- Data: array of {play, wp, event} from the sim. Extracted during simulateGame.
- Animation: line draws progressively (stroke-dashoffset animation) over 2s, respecting reduced motion.
- Mobile: graph scales to 390px width; touch to see tooltip.

CSS:
```css
.wp-graph { width: 100%; height: 120px; background: var(--panel); border-radius: var(--radius-sm); padding: 8px; }
.wp-line { fill: none; stroke: var(--team-primary); stroke-width: 2; stroke-dasharray: 1000; stroke-dashoffset: 1000; animation: drawLine 2s ease-out forwards; }
@keyframes drawLine { to { stroke-dashoffset: 0; } }
.wp-dot { r: 3; fill: var(--gold); }
.wp-dot.turnover { fill: var(--bad); }
.wp-axis { stroke: var(--border); stroke-width: 0.5; }
@media (prefers-reduced-motion: reduce) { .wp-line { animation: none; stroke-dashoffset: 0; } }
```
