### 4. BEAM Review #2 Findings (VERIFIED as Defects)

**Finding #1 - Elimination Logic Bug (DEFECT):**
The proposal's `advancePlayoffRound()` modification checks:
```javascript
const games = seasonState.playoffRounds[rk];
const userAlive = games.some(g=>g.home===user || g.away===user);
```
This is **incorrect** — after `simulatePlayoffRound()` runs, if the user played in the round, `userAlive` is always true (they're in the games). The check should determine if the user **won** their game:
```javascript
const ug = games.find(g=>g.home===user || g.away===user);
const userWon = g => g.result && ((g.result.homeScore>g.result.awayScore) === (g.home===user));
if(ug && !userWon) { /* eliminated */ }
```

**Finding #2 - Re-simulates Current Round (DEFECT):**
```javascript
for(let i=currentIdx; i<order.length; i++){
  const games = seasonState.playoffRounds[rk];
  playGame(g, true); // g already has result from simulation!
}
```
Starts at `currentIdx`, but games there are already simulated. Should start at `currentIdx + 1`.

**Finding #3 - Missing startPlayoffs() in simPlayoffsBtn (DEFECT):**
```javascript
// Proposal:
document.getElementById('simPlayoffsBtn').addEventListener('click', ()=>{ 
  simulateRemainingPlayoffs(); 
  seasonState.phase = 'complete';
  renderSeasonTab(container); 
});
```
Original: `startPlayoffs(); for(...) simulatePlayoffRound()...`
If `simPlayoffsBtn` clicked before playoffs started, `seasonState.playoffRounds` is undefined.

**Finding #6 - simRestBtn Inconsistent (DEFECT):**
Proposal modifies `simPlayoffsBtn` but not `simRestBtn` (l.4000). Either update both or make one consistent.

**Finding #4/5 - nextRoundBtn/elimination Branch (DEFENSIVE):**
If user is eliminated, `renderPlayoffsView` advances to `phase='complete'` so `nextRoundBtn` never shows. The check is defensive but could be dead code.
