## What breaks (trying to break it)

1. **Missing `</div>` at proposal line 108**: `return `<div class="kp-column ${isUser ? 'user' : ''}">${card}`;` — the `kp-column` div is never closed. This will break HTML parsing and layout.

2. **`textShimmer` keyframes don't exist.** The CSS uses `animation: textShimmer 2.5s ease-in-out infinite` in 5 places (`.star-name.shimmer`, `.star-ovr.shimmer`, `.kp-name.shimmer`, `.kp-ovr.shimmer`, plus light-mode override). These keyframes are added by P-077/P-101/P-058 but don't exist yet. Without them, shimmer text won't animate.

3. **`Cinzel Decorative` font not loaded.** Used in `.star-ovr`, `.kp-ovr`, `.identity-grade`. Depends on P-183. Without it, falls back to serif/sans-serif.

4. **`grade.toFixed(1)` violates "integers only"** (P-183). `.identity-grade` shows `grade.toFixed(1)` (e.g., "78.5") — should be `Math.round(grade)`.

5. **`star-85` uses `var(--accent)` (blue `#4f8cff`) instead of team color.** Owner wants 85+ players "more vibrant in their color" — using blue accent doesn't match. Should use `var(--team-primary, var(--gold))`.

6. **`getTeamColor` / `TEAM_PRIMARY_COLORS` duplicate P-004 data.** P-004 should be the single source of truth for team colors. Embedding a second 32-team table risks divergence. The `getTeamColor` fallback `#4f8cff` is `--accent` (blue).

7. **`notablePlayers` doesn't set `p.team`.** `renderKeyPlayersHTML` checks `p.name===mvp.name && p.team===mvp.team` but `notablePlayers(side)` returns players from `side.players` without adding a `team` property. The MVP star detection may never match.

8. **No mobile CSS for 390px.** The proposal mentions mobile in the checklist but provides no `@media (max-width:760px)` overrides for `.stars-grid`, `.kp-grid`, `.identity-bars`. Cards will overflow horizontally on mobile.

9. **`renderIdentityPanel` replacement loses `<thead>` structure.** The current code has `<table><thead><tr><th>Unit</th><th>Grade</th><th>League rank</th></tr></thead><tbody>${rows}</tbody></table>`. The proposal replaces with `<div class="identity-bars">${rows}</div>` — this drops the table header entirely, which is fine for the redesign but needs the `<details>` wrapper preserved correctly.
