## Defects found (new, beyond vl/beam)

1. **`lineupPanelHTML` passes a slotmap where a roster is expected.** Snippet: `lineupEditorHTML(seasonState.teams[user].slotmap, 'lineupSeason')`. But `lineupEditorHTML(roster, hostId)` does `Object.values(roster.slots)` (l.1278). `seasonState.teams[user]` has `.slotmap`, not `.slots`. Fix: keep the original `const roster = draftSim.rosters.find(r=>r.isUser);` and only swap the header. (vl/beam did not catch this.)

2. **`renderLineupMatchupMath` never renders.** It guards on `S.opponent`, which does not exist anywhere in the codebase. Derive the opponent from the current week's schedule game (same pattern as l.3898: `const myGame = seasonState.schedule.find(g=>g.week===seasonState.currentWeek && (g.home===user||g.away===user)); const opp = myGame ? (myGame.home===user ? myGame.away : myGame.home) : null; if(!opp) return '';`). Also guard the preseason/bye case. (New.)

3. **`zpbTeamLogo` does not exist** (beam's claim otherwise). The snippet's `typeof zpbTeamLogo==='function' ? zpbTeamLogo(user) : TEAM_ABBR[user]` is safe and falls back to the abbreviation, which is acceptable as a text logo. Note for the Architect: if a real logo helper exists under another name, swap it. (Correcting beam.)

4. **Removes "What is a flex?" details and subtitle** without Owner request (vl flagged). Recommend restoring them to avoid unrequested content loss. (Restating vl.)

5. **Integers-only nuance for win values.** vl/beam flagged every `.toFixed()` in the snippet. But `adv.gain`, `v` (group OVR averages) and `diff` (unit rating deltas) are fractional by nature: rounding `adv.gain` (≈0.45 wins) to an integer gives 0 and hides the recommendation. Recommend:
   - OVR/counts/ranks → integers (`Math.round`).
   - Group score averages and unit rating diffs → keep one decimal (they are averages/deltas, not counts).
   - Win gains → two decimals (it is a win delta; rounding to integer is meaningless).
   - `wpo` (wins per OVR) → three decimals (it is a rate).
   This is a judgment call for the Architect; the prior reviews' blanket "Math.round everything" would break the win-gain display. (New insight.)

6. **Invalid mobile CSS nested selector** (vl flagged). Provide corrected flat rules.

7. **`#fff` in shimmer gradients** (vl flagged; beam's "no #fff found" is wrong — the snippet uses `linear-gradient(90deg,var(--gold),#fff,var(--gold))` in sections 3, 6, 7 and the `.shimmer` CSS). Replace with `var(--text)`.

8. **`Cinzel Decorative` not loaded** (vl flagged) — use `var(--display-font, serif)`.

9. **`getTeamColor` does not exist** (vl flagged) — depends on P-004; fallback must be `var(--gold)`, not blue.

10. **`lineupScoresHTML` CSS selector mismatch.** The snippet adds `.lineupScores > div { border-left: 3px solid var(--team-primary, var(--gold)); }`, but the rendered divs have no `lineupScores` class (they are plain `<div style="flex:1;...">`). function renderLineupMatchupMath(roster, hostId){
  const S = seasonState;
  const user = seasonUserTeam();
  const myGame = S.schedule.find(g=>g.week===S.currentWeek && (g.home===user||g.away===user));
  const opp = myGame ? (myGame.home===user ? myGame.away : myGame.home) : null;
  if(!S || !opp) return '';
  const oppRatings = S.unitRatings[opp];
  const myRatings = S.unitRatings[user];
  const oppRanks = S.unitRanks[opp];
  const myRanks = S.unitRanks[user];
  const slotToUnit = { /* as in snippet */ };
  const rows = ROSTER_SLOTS.map(sl=>{
    const p = roster.slots[sl];
    if(!p) return '';
    const unit = slotToUnit[sl];
    if(!unit) return '';
    const myVal = myRatings[unit] || 0;
    const oppVal = oppRatings[unit] || 0;
    const myRank = myRanks[unit] || 32;
    const oppRank = oppRanks[unit] || 32;
    const diff = myVal - oppVal;
    const favor = diff > 0 ? 'us' : diff < 0 ? 'them' : 'even';
    const star90 = p[3] >= 90, star85 = p[3] >= 85;
    const nameStyle = star90 ? 'shimmer' : star85 ? 'vibrant' : '';
    return `
      <div class="matchup-row ${favor}" data-slot="${sl}">
        <span class="matchup-slot">${LABELS[sl]||sl}</span>
        <span class="matchup-player ${nameStyle}">${p[0]}</span>
        <span class="matchup-unit">${UNIT_INFO[unit]?.label || unit}</span>
        <div class="matchup-bar">
          <div class="matchup-fill ${favor}" style="width:${Math.min(Math.abs(diff)/15*100, 100)}%"></div>
        </div>
        <span class="matchup-diff ${favor}">${diff>=0?'+':''}${Math.round(diff)}</span>
        <span class="matchup-rank">#${myRank} vs #${oppRank}</span>
      </div>
    `;
  }).filter(Boolean).join('');
  if(!rows) return '';
  return `
    <details class="panel" style="margin-top:12px;">
      <summary style="cursor:pointer;font-weight:700;">Matchup Math (roster order)</summary>
      <div class="matchup-math-roster">${rows}</div>
    </details>
  `;
}
