## P-115 REFINEMENTS TO ADD TO P-007 SPEC

### 1. **Turnover Display: Every Turnover Shown**

**Current:** Turnovers included in `homeEvents`/`awayEvents` with `type:'TO'`

**Refinement:**
```javascript
// In makeScoringEvents or animateGame:
// Each turnover event gets special treatment
{
  type: 'TO',
  subtype: 'INT' | 'FUM', // interception vs fumble
  side: 'home' | 'away',
  player: 'Player Name', // who forced it / recovered it
  pts: 0,
  q: quarter,
  t: time,
  turnoverType: 'interception' | 'fumble'
}
```

**Visual:**
- Red flash overlay (0.3s) on turnover
- Large "INT" or "FUM" badge in team color
- Player name who forced/recovered
- Pause 1.5s before continuing

### 2. **Scoring Display: "+x" in Scoring Team's Color**

**Current:** Score updates shown in quarter totals

**Refinement:** Floating "+7" / "+3" / "+2" animation when score changes

```css
.score-pop {
  position: absolute;
  font-family: 'Cinzel Decorative', serif;
  font-size: 1.5rem;
  font-weight: 900;
  pointer-events: none;
  animation: scorePop 1.2s ease-out forwards;
  z-index: 100;
}
.score-pop.home { color: var(--team-primary); }
.score-pop.away { color: var(--opp-primary); }
@keyframes scorePop {
  0% { transform: translateY(0) scale(1); opacity: 1; }
  100% { transform: translateY(-60px) scale(1.5); opacity: 0; }
}
```

**JS:** On each scoring event, spawn `.score-pop` at center, animate upward.

### 5. **Skip Button Behavior**

**Current:** Skip visible throughout

**Refinement:**
- Skip button visible during animation
- **Disappears at the end** (when final whistle blows)
- After final whistle: Skip → "CONTINUE" button
- If user won: "CONTINUE" button has shimmering star ✦

```javascript
// In animateGame final phase:
function showFinalVerdict(won){
  const skipBtn = document.getElementById('animSkip');
  if(skipBtn) skipBtn.style.display = 'none';
  
  const continueBtn = document.createElement('button');
  continueBtn.className = 'resetbtn zpb-continue';
  continueBtn.textContent = won ? 'CONTINUE ✦' : 'CONTINUE';
  continueBtn.style.cssText = 'width:auto;padding:14px 40px;font-size:1.1rem;font-family:"Cinzel Decorative",serif;font-weight:900;';
  continueBtn.onclick = () => { /* close animation, show score tables */ };
  document.body.appendChild(continueBtn);
}
```
