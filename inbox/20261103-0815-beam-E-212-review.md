## Findings
1. Contract count: §3 lists **10** contracts; the spec lists **9** and omits `ensureRatings` (#6). Add it.
2. "slotWins family", "season scaffolding" and "awards" are families, not single functions. The spec must name every member so the tool hashes each, not one representative (a representative can mask a sub-function change). Beam's own 24 Oct run hashed one per family and flagged this as a caveat (INFERRED).
3. Extraction must take the **last** definition of each function, not the first. The handoff §4.1 (payload override order): w13/w27/w29/w30/w32 script blocks re-bind earlier declarations; the last definition wins at parse time. The spec's "extract function bodies" does not state this; an implementation that takes the first occurrence would hash a stale body. (Beam's Python prototype took the first occurrence and flagged this as unverified.)
4. The tool must concatenate all inline `<script>` blocks (lint.mjs extract does this) and skip external `src=` scripts, matching the product's actual parse.
5. Hash input should be the raw body (signature + braces + whitespace) as the spec says, but the spec should state that a reformat-only change will flip the hash; offer an optional `--normalize` (whitespace-collapsed) mode for noise filtering. Default stays raw.
6. Missing functions must be reported as `MISSING`, not crash the run (some contracts may be absent in older builds).
7. Inputs are two HTML files; the spec's "previous wN / new wN" is fine but should note the tool works on any two single-file builds (Pre-Colors vs a w build, or w33 vs w55), and that w builds live outside the repo (not on council/base).
8. Evidence: the spec requires "test results on at least one pair" but none attached. Verified feasibility below on w33 vs w55.

**Title:** E-212: Seam watch — function-hash diff of the ten seam contracts between two builds

**File to create:** `tools/seam-watch.mjs` (Node, no dependencies, reads only).

**Inputs:** `node tools/seam-watch.mjs <old.html> <new.html> [--normalize] [--json]`

**Contract manifest (all members of each family — 27 functions):**
- simulateGame
- buildGameDetail (plus buildOffenseDetail, buildDefenseDetail if present)
- teamRatings
- matchupModel
- slotWins, slotWinsTable, effOvr, flexPenaltyFor, isNaturalSlot, playerWar, winsAt, lineupWins, optimalLineup

- modelWeights, computeScore
- computeStandings, computeSeeding, playGame, simulateCurrentWeek, advanceWeek, simulatePlayoffRound, startPlayoffs (plus buildWildCardRound, buildDivisionalRound, buildConfChampRound, buildSuperBowl if present)
- honorCandidates, computeRegularSeasonAwards, computePlayoffAwards

**Method:**
1. Extract all inline `<script>` blocks in document order (skip external `src=`), concatenate.
2. For each contract function, find the **last** occurrence of `function <name>` (payload overrides).
3. Brace-count from the first `{`, respecting string literals and escapes, to capture the full body including signature.
4. sha256 the raw body (or whitespace-collapsed body with `--normalize`), first 12 hex.
5. Missing function → `MISSING` row, not an error.

**Output:**
```

CHANGED (N of M):
  <fn>: old=<hash> new=<hash>
UNCHANGED (M-N of M):
  <fn>: same=<hash>
MISSING (K): <fn> (old|new|both)
```
Exit 0 always (this is a measurement tool). `--json` emits `{changed:[],unchanged:[],missing:[]}`.

**How to check:**
```
node tools/seam-watch.mjs /tmp/w33.html /tmp/w55.html
```
