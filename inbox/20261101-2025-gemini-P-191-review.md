### Verification & Mathematical Derivation

#### 1. `RET_PTS = 2.36` Calibration & Split Derivation
* **Field Position Valuation**: Standard NFL analytics values 1 yard of field position at **~0.04 points** (0.035–0.045 EPA/yard in the 25–35 yard line range).
* **Pre-2025 Baseline Return Yardage (2020–2024 Avg from UK's PFR table)**:
  * Kick Return Yards / Game = **40.56 yards**
  * Punt Return Yards / Game = **15.24 yards**
  * Total Return Yards / Game = **55.80 yards**
  * Total Point Value = $55.80 \text{ yds/game} \times 0.04 \text{ pts/yd} = \mathbf{2.232 \text{ pts/game}}$, calibrating closely to the engine's baseline $\mathbf{RET\_PTS = 2.36}$.
* **Yardage-Based Split (Pre-2025)**:
  * Kick Return Share = $40.56 / 55.80 = 72.69\%$
  * Punt Return Share = $15.24 / 55.80 = 27.31\%$
  * Yardage-proportional split of $2.36$: $\text{KR\_PTS} = \mathbf{1.72}$, $\text{PR\_PTS} = \mathbf{0.64}$.
* **Leverage/Variance Adjustment (Spec's 1.50 / 0.86 Split)**:
  * `ENGINE-MATH-SPEC.md` uses $\text{KR\_PTS} = \mathbf{1.50}$ ($63.6\%$) and $\text{PR\_PTS} = \mathbf{0.86}$ ($36.4\%$).
  * The higher weight on Punt Returns ($0.86$ vs pure yardage $0.64$) reflects the higher win-probability leverage, shorter field position, and higher turnover/muff risk of punt returns relative to kickoff touchback-heavy baselines.
* **2025 Dynamic Kickoff Rule Shift**:
  * 2025 KR Yards/Game = **99.0 yards**, PR Yards/Game = **15.5 yards** (KR share = $86.5\%$).
  * Under 2025 rules with $2.36$ total: $\text{KR\_PTS} = \mathbf{2.04}$, $\text{PR\_PTS} = \mathbf{0.32}$.

#### 2. `PUNT_PTS = 1.084` Derivation
* **Punting Baseline (2020–2025 Avg)**:
  * Punts per game = **3.8 punts/game**
  * Net Punting Average = **41.1 yards/punt**
* **Impact of Elite Punter ($P = 90$ vs $P = 80$)**:
  * An elite punter improves net punting by $\sim 3.0$ yards/punt.
  * Field position gain per game = $3.8 \text{ punts} \times 3.0 \text{ yds} = 11.4 \text{ net yards/game}$.
  * Point differential = $11.4 \text{ yds} \times 0.04 \text{ pts/yd} = \mathbf{0.456 \text{ pts/game}}$.
  * Over 17 games ($35\text{ pts/win}$), $0.456 \times 17 / 35 = \mathbf{\sim 0.22 \text{ wins}}$, confirming the spec's target of $0.25$ wins for a $70 \rightarrow 90$ punter step (half a kicker).
* **Matchup Term Calibration**:
  * Term: $-\text{PUNT\_PTS} \times \left(\exp\left(\frac{P-80}{45}\right) - \exp\left(\frac{lg.P-80}{45}\right)\right)$
  * For $P=90, lg.P=80$: $\exp(10/45) - 1 = 1.2488 - 1 = 0.2488$.
  * With $\text{PUNT\_PTS} = 1.084$, points impact $= 1.084 \times 0.2488 = 0.27 \text{ pts/game} = \mathbf{0.13 \text{ wins}}$ per team per game ($0.25\text{ wins}$ for a $70 \rightarrow 90$ delta).
