# Findings (numbered)

1. **Anchor error — init line.** Work item and proposal both cite "init near setActiveTab (l.3936)". Line 3936 is inside `startNewDraftFlow()`, not init. The top-level init is the last JS line, 6550. The load path must hook at 6550 (OR's Patch P2 anchors the same spot correctly). Also the proposal's "resume prompt on init" will fire on every cold load; reconcile with the existing `goDraftResumeBtn` (l.866) so there are not two competing resume affordances.

2. **Anchor error — preseason transitions.** Cited "scriptLocked transitions (l.3544/3556)" are `simulateCurrentWeek` start and `simRestOfSeason` start, not preseason finalisation. The actual preseason→season transition is l.5120 (`S.preseason = false`). Save hooks should be: l.5120 (preseason finalise), l.3543 (simulateCurrentWeek end), l.3556 (simRestOfSeason), playoff round loop at l.3961, and lineup apply (wireLineupEditor callback). Also `beginPlayoffsBtn` → `startPlayoffs()` (l.3952/3960).

3. **Restore can stall the draft.** Save points are "after each pick: executePick end". But `executePick` runs inside the `processUntilUserTurn` loop (l.1451 region) and also inside `makeUserPick2` (l.1805, which calls executePick then processUntilUserTurn). Saving at executePick end captures a state with `awaitingUser === false` and an advanced `pos`, but the loop is no longer running on restore, so the draft stalls. Fix: restore then call `processUntilUserTurn()` if `!draftSim.awaitingUser && draftSim.pos < draftSim.order.length`; and also save at `makeUserPick2` end (after processUntilUserTurn) and at `finishDraft2`.

4. **Resume routing is wrong.** Code 9.2 always calls `goSeason()`. For a draft in progress (`pos < 32*26`) that lands on the "Draft your team / Continue draft in progress" hero instead of restoring the live board. Route: if `draftSim && pos < 32*26` → `setActiveTab('viewDraft','tabDraftBtn')` then `processUntilUserTurn()` (guarded); else `goSeason()`.

5. **Failure-mode code does not match spec.** Code 9.1 has an empty `catch (e) {}`. T5 requires: (a) quota-exceeded → warn "Save failed (storage full)"; (b) localStorage unavailable (private mode) → skip silently and show "Saving disabled in private mode" once. Need a feature test (`try { localStorage.setItem('__mds_t','1'); localStorage.removeItem('__mds_t'); } catch(e){ disabled = true; }`) and differentiated handling. Also "show once" needs a flag.

6. **No beforeunload / visibilitychange.** Beam's code has no immediate save on unload, so the last ≤300 ms of edits are lost on refresh. Adopt OR's `beforeunload` + `visibilitychange` (immediate `saveNow()`, not debounced). Also call `saveNow()` at the start of `exportSave()` so export is not stale.

7. **Seeded RNG conversion scope is incomplete.** T5 says "draft only: cpuPick, executePick, startDraft2 shuffle" and claims "same seed ⇒ same draft". But `cpuPick` (l.1400) calls `cpuNoise` (l.1396, uses `Math.random`), `cpuMiss` (uses `Math.random`), `cpuBias` (l.1390, uses `Math.random`), and `randNormal` (l.1920, uses `Math.random`). Also `startDraft2` uses `Math.random` for the `__random` user-team pick (l.1464) and two inline shuffles (l.1466, l.1474), and `shuffleArr` (l.1015) is used in season/game paths and must NOT be touched. Unless all draft-path `Math.random` calls route through `rnd()`, two runs with the same seed will diverge. Conversion list must be: `cpuNoise`, `cpuMiss`, `cpuBias`, `randNormal`, the `__random` pick, and the two inline shuffles — with `setSeed()` called at the top of `startDraft2` before any of them, reading the seed input. `pick()` (draft recap prose) may stay `Math.random` (cosmetic only) — state that explicitly.

8. **Size / keep-list unspecified.** Code 9.1 saves `draftSim` wholesale, including `pool` (1,200 players), `undoStack` (full snapshots per pick), `repl`/`replPool` caches, `noiseSd`/`missP`/`bias` caches. T5 forbids > ~1.5 MB and requires a keep-list stripping caches/UI state. Recommend: strip `undoStack`, `repl`, `replPool` on save (rebuild empty on restore; losing undo on refresh is acceptable), keep `noiseSd`/`missP`/`bias` (needed for reproducibility), and measure the resulting blob size before shipping (add a `console.log`/assert in dev). `seasonState.planCache` can be stripped too (recomputable). Also `league100` is not saved (fine — it's a side view).

9. **Schema: stick to T5's single key.** OR's proposal uses five `ffs_*` keys and renames the storage module. That violates T5's "ONE key, `mds_` prefix" and is out of scope for P-011. Recommendation: keep `mds_save_v1` per T5; if weights/UI-prefs persistence is wanted, file it as a separate item (it touches protected-ish weight handling and should not ride on P-011).

10. **Export/Import gaps.** `exportSave` reads the raw stored string, which may be up to 300 ms stale (debounce) — call `saveNow()` first. `importSave` does not validate shape beyond `v === 1` (a malformed blob with `v:1` but no draftSim/seasonState will crash on restore). Add a minimal shape check (`typeof b.draftSim === 'object' || b.draftSim === null`, etc.) and a confirm before reload. After import + reload, the resume prompt appears; acceptable, but consider auto-resume when import was the source (optional, note as open question).

11. **Resume prompt UX / existing affordance.** The toast (`fxtoast`) plus the existing "Continue draft in progress" button (l.866) overlap. Either remove the button in favour of the toast, or keep the button and make the toast draft-only. Recommend: keep toast as the primary resume mechanism and demote the button to "if toast dismissed". Also the toast must be dismissible and not block the page.

12. **Saved-at line placement.** "under the Season panel hero" — the season hero is `renderSeasonTabInner`'s `hero-panel` (l.850) when no seasonState, and the main panel when seasonState exists. Put `<div class="narr" id="savedAtLine" …>` in both, or only update when present (code already null-guards). Fine, but anchor it explicitly so the Architect knows where.

13. **Undo stack size.** `makeUserPick2` pushes a full snapshot (pool copy + all roster slots) per pick. Saving this in `mds_save_v1` multiplies size. Strip it on save (finding 8) and document that undo is session-only.

## 9.1 Save/load helpers (corrected)

```js
const SAVE_KEY = "mds_save_v1";
let __storageDisabled = false;
try { localStorage.setItem("__mds_t", "1"); localStorage.removeItem("__mds_t"); }
catch (e) { __storageDisabled = true; }
let __privateMsgShown = false;

function scheduleSave() { clearTimeout(window.__saveT); window.__saveT = setTimeout(saveNow, 300); }

function saveNow() {
  if (__storageDisabled) {
    if (!__privateMsgShown) { __privateMsgShown = true; console.warn("Saving disabled in private mode"); }
    return;
  }
  try {
    const draftSimToSave = (typeof draftSim !== "undefined" && draftSim) ? {
      userIndex: draftSim.userIndex, rosters: draftSim.rosters, teamNames: draftSim.teamNames,
      pool: draftSim.pool, order: draftSim.order, pos: draftSim.pos, log: draftSim.log,
      awaitingUser: draftSim.awaitingUser, bias: draftSim.bias, noiseSd: draftSim.noiseSd,
      missP: draftSim.missP, rngSeed: draftSim.rngSeed, repl: null, replPool: null,
      undoStack: []   // session-only
    } : null;
    const seasonStateToSave = (typeof seasonState !== "undefined" && seasonState) ? {
      ...seasonState, planCache: null
    } : null;
    const blob = { v: 1, savedAt: new Date().toISOString(), draftSim: draftSimToSave, seasonState: seasonStateToSave };
    const s = JSON.stringify(blob);
    if (s.length > 1.5 * 1024 * 1024) console.warn("Save blob too large:", s.length);
    localStorage.setItem(SAVE_KEY, s);
    const line = document.getElementById("savedAtLine");
    if (line) line.textContent = "Season saved locally at " + new Date().toLocaleTimeString();
  } catch (e) {
    console.warn("Save failed (storage full)");
  }
}

function loadSave() {
  if (__storageDisabled) return null;
  try {
    const raw = localStorage.getItem(SAVE_KEY);
    if (!raw) return null;
    const b = JSON.parse(raw);
    if (!b || b.v !== 1) return null;
    if (b.draftSim !== null && typeof b.draftSim !== "object") return null;
    if (b.seasonState !== null && typeof b.seasonState !== "object") return null;
    return b;
  } catch (e) { return null; }
}

function clearSave() { try { localStorage.removeItem(SAVE_KEY); } catch (e) {} }
```

## 9.3 Export / Import (corrected)

```js
function exportSave() {
  saveNow();
  const raw = localStorage.getItem(SAVE_KEY) || "{}";
  const blob = new Blob([raw], { type: "application/json" });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url; a.download = "mds-save-" + Date.now() + ".json"; a.click();
  URL.revokeObjectURL(url);
}
function importSave(file) {
  const r = new FileReader();
  r.onload = () => {
    try {
      const b = JSON.parse(r.result);
      if (!b || b.v !== 1) { alert("Unsupported save version"); return; }
      if ((b.draftSim !== null && typeof b.draftSim !== "object") ||
          (b.seasonState !== null && typeof b.seasonState !== "object")) { alert("Invalid save file"); return; }
      if (!confirm("Replace current saved season with this file?")) return;
      localStorage.setItem(SAVE_KEY, JSON.stringify(b));
      location.reload();
    } catch (e) { alert("Invalid save file"); }
  };
  r.readAsText(file);
}
```

## 9.4 Seeded RNG (corrected conversion list)

```js
let RNG_SEED = null;
function mulberry32(a) { return function () { a |= 0; a = (a + 0x6D2B79F5) | 0; let t = Math.imul(a ^ (a >>> 15), 1 | a); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; }; }
let _rng = Math.random;
function rnd() { return _rng(); }
function setSeed(seed) { RNG_SEED = seed; _rng = (seed == null) ? Math.random : mulberry32(seed); }
```
