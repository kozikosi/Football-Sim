## DEFECTS (shown — JS integration will not run as written)
1. **`zpbKick` undefined — ReferenceError.** uk's integration calls `showWelcomeCine(zpbKick)` and falls back to `zpbKick()` (spec lines 241, 244). `zpbKick` has 0 occurrences in Football-Sim-PreColors.html. The draft actually starts via `processUntilUserTurn()` at the end of `startDraft2` (line ~1507). `onComplete` must be `processUntilUserTurn` (or a wrapper), not `zpbKick`.
2. **`zpbStartDraftWatchdog` undefined — ReferenceError.** uk calls it unconditionally after the cinematic (spec line 247). 0 occurrences in product. Remove or replace.
3. **Integration point misidentified.** uk says "replace the cinematic block around line 1455: OLD try{...zpbWelcomeCine(zpbKick)...}". `startDraft2` (line 1455) contains no such block — it sets up draft UI/teams and calls `processUntilUserTurn()` directly. Correct integration: split `startDraft2` so the cinematic shows first, then `processUntilUserTurn()` runs on complete; or call `showWelcomeCine(() => { /* remaining draft start */ })` from `startDraft2` before `processUntilUserTurn`.
4. **Skip overlay unclickable.** `.welcome-cine` sets `pointer-events: none` (spec line 49) and `.welcome-cine__skip` (a child) does NOT reset `pointer-events: auto`, so clicks never reach the skip overlay. uk's comment says "overlay handles skip" but the parent blocks it. Fix: add `pointer-events: auto` to `.welcome-cine__skip` (and keep text non-interactive via a separate wrapper or `pointer-events: none` only on text elements).
5. **`zpbWelcomeCine` claim is accurate but integration targets don't exist.** uk correctly notes zpbWelcomeCine is Z-post-blue-only, not Pre-Colors — but then proposes calling `zpbKick`/`zpbStartDraftWatchdog`, which are equally absent.
