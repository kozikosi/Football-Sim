**Working ovrEq definition (Super, not yet Architect-blessed):**
- `ovrEq = winsLost / slope[dest]`, `winsLost = max(0, slotWins(natural, ovr) − slotWins(dest, ovr))`
- `slope[dest] = slotWins20(dest_slot) / 20` (the Colors engine has no `slotWinsPerOvr()`)
- `P(a→b, ovr) = clamp(round2(θ · ovrEq(a→b, ovr)), 0, 30)`
- θ ∈ {0.5, 0.75, 1.0}, ovr ∈ {85, 90}
- natural slot = primary (highest-weight) slot for the role's dest; dest slot = primary slot for the flex destination
