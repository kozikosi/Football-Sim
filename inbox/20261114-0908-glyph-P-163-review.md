## FINDINGS

1. **Team palette source missing (defect):** UK proposes `teamPalette = team => TEAM_DATA[team]?.primary || '#FFD700'` and uses it for star/heading/name colours. In this ref build TEAM_DATA stores roster slots, not team brand colours/primary hex values; no `getTeamColors`/`TEAM_COLORS` helper exists. Result: all "team-coloured" elements fall back to gold, failing "star emojis team-coloured..." and "Playoff picture text in palette colours". Spec must name an actual palette source available in target build (e.g. CSS vars, existing team-colour map, or define one) with anchors.
2. **Font not loadable as written (defect):** "Whole game preview in Cinzel Decorative" requires the font to be available. Ref contains no Cinzel reference/import; adding `font-family:'Cinzel Decorative',Georgia,serif` alone degrades to Georgia. Spec must include font loading (existing project mechanism or explicit `@import`/`<link>` anchor) or state the available fallback target.
3. **Over-broad matchup filter (defect/risk):** UK replaces matchup lines with `.filter(line => !line.includes('quarterback play') && !line.includes('pass protection'))`. Because `matchupLines` uses `UNIT_INFO` shorts `quarterback play` and `pass protection` as regular labels in generated sentences, this will drop legitimate matchup lines for QB and OL-pass-protection units (and any text containing those substrings), not only the specific "quarterback play +3.3 pass protection" artifact named in P-163. A targeted removal (exact artifact string if present, or a narrower condition scoped to the bad phrase/shape) is required.
4. **Shimmer implementation incomplete (risk):** UK adds `@keyframes shimmer` and inline `animation:shimmer ...` on 90+ stars but defines no `.playoff-star-card` layout rules/CSS class behavior beyond inline styles and no `prefers-reduced-motion` fallback. Inline animation on text may conflict with existing motion policy; spec should include reduced-motion handling and confirm keyframes are added once (style block anchor) without clashing with existing naming.
5. **Scope note (calibration):** UK states "Whole game preview in Cinzel Decorative" and applies Cinzel to headline and wrapped preview div, but `g.preview` is HTML paragraphs generated by `playoffPreview`/`regularPreview` text paths (no font styling inside). Wrapping sets inherited font (mostly OK), yet "Playoff picture text in palette colours" is not concretely addressed inside generated paragraph text except incidental inheritance — spec should identify where palette colours apply (labels, team names, scores, all body text?) and how.
6. **Target/build staleness context (risk):** Spec is correctly anchored to PreColors `40233d6b...`, but live work is on Z-post-blue waves / Colors tracks; this is a PreColors-targeted proposal. If P-163 is to be built on a different shell, anchors/snippets must be re-targeted — reviewers should not treat this as directly applicable without re-measurement.
