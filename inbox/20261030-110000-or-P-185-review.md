FINDING: The zpbPackFor algorithm from Z-post-blue (origin/main z-core/01-html) is a complete WCAG-compliant team-colour palette generator. It takes each team's 3 hexes from ZPB_TEAM_COLORS and generates 30+ CSS custom properties guaranteeing minimum 4.6:1 contrast on both light (#fcf7f1) and dark (#181114) backgrounds. The algorithm:

1. Preserves the team's brand primary colour (P) where already readable
2. For dark-on-dark combos, iteratively shifts HSL luminance in 0.015 steps until contrast >= 4.6:1
3. Generates derived tones (g1–g6, g1d–g6d) for backgrounds, borders, text, etc.
4. Keeps hue and saturation constant — only L value changes (tone-lift, not color-shift)
