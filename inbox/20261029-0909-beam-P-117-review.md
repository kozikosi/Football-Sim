## Additional findings vs review #1 (vl)

1. **Persistent hero = global exposure.** The proposal puts `zpb-20-0-header` inside the global `.hero` (l.319) with `position:absolute;top:16px;right:16px`. That header renders on every view (rankings, draft board, season, playoffs), violating Owner rule #1 ("shown only on the draft review page and the season header"). Fix: gate the element behind a view/phase flag, or inject it only inside `renderRegularSeasonView`/the draft-complete panel, not the global hero. Keep the hero untouched.

2. **Shimmer on light backgrounds.** `.zpb-shine.gold` uses `linear-gradient(90deg, var(--gold), #fff, var(--gold))`. On the near-white team tints the Owner wants (P-004), `#fff` is invisible. Use a gold-only shimmer (`var(--gold)` → a darker gold → `var(--gold)`) or define `--gold-deep` for light mode (contrast audit Q-V23-2). Note dependency on P-111/P-183 for the foil style.

3. **Mobile collision at 390px.** `position:absolute` top-right of a flex hero with the stepper on the right will overlap the stepper on narrow screens. The 760px breakpoint is too coarse; add a 390px rule (stack below hero or hide). Test at 390px per §10.

4. **Draft-complete header introduces more unimplemented classes.** `<h2 class="foil-shimmer gold">` and `.draft-complete-header` need CSS that does not exist yet (P-111). Document as dependency; do not ship partial.

5. **"Your draft is in the books" removal vs replacement.** Owner #4 says remove the line "elsewhere"; the proposal swaps it for "Coach your team to the Super Bowl." That is a content change, not a pure removal — acceptable, but name it as a copy decision so the Architect can confirm. Keep the dsub variant only on the draft-complete panel.

6. **Font load.** `Cinzel Decorative` is not in Pre-Colors (0 hits). Confirm P-111/P-183 lands before this; fallback to system serif in the meantime.

7. **cygFade timing.** 4s cycle matches "slowly fades"; OK. Add `prefers-reduced-motion` (already in proposal) — keep.
