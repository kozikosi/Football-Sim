## Sound design spec

### What it does
Optional sound effects for key game events: whistle on snap, crowd cheer on TD, crowd groan on turnover, referee whistle on penalty, crowd murmur during close games. All sounds are short (<1s) and non-intrusive.

### Implementation
- Use the Web Audio API (no external files, one HTML file constraint).
- Generate sounds programmatically (oscillators, noise buffers) — no audio files needed.
- Volume control: master volume slider in settings (0-100%, default 50%).
- Mute button: one-click mute, persisted in localStorage (if available).
- Reduced motion: sounds off when prefers-reduced-motion is set (accessibility).

### Sound events
| Event | Sound | Duration |
|---|---|---|
| Game start (kickoff) | Whistle + crowd murmur | 0.5s |
| Touchdown | Crowd cheer + horn | 1s |
| Field goal | Crowd cheer (quieter) | 0.5s |
| Turnover (INT/fumble) | Crowd gasp + whistle | 0.5s |
| Sack | Crowd reaction | 0.3s |
| Game end (win) | Fanfare | 1s |
| Game end (loss) | Subdued tone | 0.5s |
| Button click | Soft click | 0.1s |

### Open questions
- Should sounds play during "Sim Season" (all games at once)? Probably not — too noisy.
- Should there be background crowd noise during the game animation? Could be nice but might be distracting.
- Should sounds be on by default or opt-in? Opt-in (default off) to avoid surprising users.

Small (INFERRED): ~150 lines of JS (Web Audio API). No external files.
