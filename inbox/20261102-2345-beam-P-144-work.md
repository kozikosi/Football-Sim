## Design: Position value tree (draft-board depth-chart order)

### Layout
A vertical tree with 28 nodes (one per roster slot), ordered by draft-board depth-chart order (QB, RB1, RB2, WR1, WR2, WR3, TE1, TE2, OT1, OT2, OG1, OG2, C, DE1, DE2, DT1, DT2, MIKE, WILL, SAM, CB1, CB2, CB3, SS, FS, K, plus DL5, TE3, WR4 for V23).

Each node shows:
- Position code (QB, RB1, etc.) in Cinzel Decorative
- Wins value (e.g., 1.0) in bold
- A horizontal bar proportional to wins (colour: gold for top 5, accent for top 10, muted for rest)

### Flex paths
Flex paths are shown as curved lines connecting positions that can flex to each other. For example:
- QB → FS (penalty -10) shown as a dashed gold line
- RB → FB/WR/TE shown as dashed lines
- TE → WR/FB shown as dashed lines
- etc.

The flex paths use the penalty as opacity: -2 (almost free) = solid line, -6 = dashed, -10 = dotted.

### Explanations (fade in/out, centred, Star-Wars style)
Four paragraphs, each fading in and out slowly (3s fade in, 2s hold, 3s fade out), centred on screen:
1. "What is a flex" — "A player can play a position he doesn't normally play, at a rating penalty. A great tackle can play guard for free; a great corner can play safety at -2."
2. "Who decides? You do." — "The board shows each player's value at the spot he would actually fill. You pick; the math tells you what it's worth."
3. "Where the wins come from" — "Every starting spot is worth a different amount. Quarterback is in a class by itself. Edge rushers and cornerbacks are the most valuable defenders."
4. "Personnel packages" — "11 personnel (1 RB, 1 TE, 3 WR) is the most common. 12 (2 TEs) and 13 (3 TEs) are used in specific situations."
