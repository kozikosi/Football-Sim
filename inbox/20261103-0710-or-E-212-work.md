## Colors v1 engine: Seam watch - list which of the ten seam contracts changed

### Specification
Track the evolution of the engine's ten seam contracts by comparing each new `wN` build against the previous one. When a newer `wN` lands, produce a function-hash diff table showing which of the ten contracts changed and which stayed the same.

### Requirements
1. **Contract list**: The ten functions listed in `HANDOFF-TO-CLAUDE.md` §3:
   - `simulateGame`
   - `buildGameDetail`
   - `teamRatings`
   - `matchupModel`
   - `slotWins` family
   - `cpuPick`
   - `modelWeights` / `computeScore`
   - `season scaffolding`
   - `awards`
2. **Hash method**: Function-body hash (not file hash) so only the function logic changes
3. **Output format**: Changed / Unchanged table with the hash of each function
4. **Repeatable**: Must run again for each new `wN` that lands

### Technical details
- File to modify: `tools/seam-watch.mjs` (create new tool)
- Inputs: previous `wN` file, new `wN` file
- Output: Table showing changed/unchanged functions with their hashes
- Method: Extract function bodies, compute SHA-256, compare

### How to check
```bash
# Run the seam watch tool
node tools/seam-watch.mjs \
  previous-wN.html \
  new-wN.html

# Expected output:
# CHANGED (3 of 10):
#   simulateGame: old=abc123 new=def456
#   teamRatings: old=ghi789 new=jkl012
#   cpuPick: old=mno345 new=pqr678
# UNCHANGED (7 of 10):
#   buildGameDetail: same=stu901
#   matchupModel: same=vwx234
#   ...
```

### Safe alone
Yes - this is a pure analysis/diff tool with no gameplay impact.
