## New idea: a generated status line from a single source-of-truth table

The c9 package's core failure mode is that the same fact (did k1 run?) is restated in 9+ files, and a hand edit to one file leaves the others drifting. The fix is structural, not editorial:

**A single `STATUS.md` at the package root, generated by a script from the receipts, never hand-edited.** The script (`scripts/gen-status.mjs`) reads the receipts directory and emits one table:

```
| Claim | Source | Value | Status |
|---|---|---|---|
| k1 shipped composite | receipts/partH-c9/k1-*.log | ABSENT | OPEN |
| k2 prepared composite | receipts/partH-c9/k2-*.log | 29,498 B, 18 × EXIT_CODE=0 | PASS |
| gate-manifest shipped | gate-manifest.mjs stdout | FAIL (.gitignore) | FAIL |
| gate-numerals shipped | gate-numerals.mjs stdout | CLEAN ×2 | PASS |
| START-OF-CHAT sha | shasum -a 256 | 15f088c7… | PASS |
| board battery | board.battery.mjs stdout | 6/6 | PASS |
| falsify-board | falsify-board.mjs stdout | exit 0, ALL DIED | PASS |
```

Every other doc (README-DELIVERY, WHAT-CHANGED, VERIFY, SHELL-STATUS) **quotes the table** rather than restating the facts. A claim that disagrees with the table is a build failure. This is Pickle's cite-check idea (A2) made concrete: the table IS the cite-check output, and the docs render from it.

**Law:** no shipped doc states a fact that the STATUS table does not carry. **Falsifier:** hand-edit one doc to claim k1 passed → the cite-check (which compares docs against the table) dies naming the file and line.

This is filed as an idea, not a build. Pickle's A2 is the right shape; this is the concrete rendering.
