# Review: P-210 Storage origin and browser behavior risks (Muse's work)

## Verification performed

### 1. file:// behavior (VERIFIED against primary sources)

| Browser | localStorage | IndexedDB | Source |
|---|---|---|---|
| Chrome/Edge | Works (shared across file://; path-based orphan risk) | Works | MDN, WHATWG html#3099 |
| Firefox | Per-file isolation | Blocked (SecurityError) | Bugzilla #643318, #1240349 |
| Safari | **Blocked (SecurityError)** | Blocked | WebKit (since Safari 11) |

**VERIFIED**: WHATWG HTML spec does not define origin for file:// (html#3099, open since 2017). Each browser made its own choice.

**Critical consequence**: Deployed `https` URL is a *requirement*, not nice-to-have. Z.ai's facade must treat `file://` as `unavailable`.

### 2. Safari 7-day eviction (VERIFIED from WebKit sources)

**Rule**: All script-writable storage (localStorage, IndexedDB, sessionStorage, SW registrations) deleted after 7 days of Safari *use* without user interaction.

**Nuances (VERIFIED)**:
- 7 days of *browser use*, not calendar days
- Interaction = click/tap/type (scrolling doesn't count)
- Returning resets clock
- `navigator.storage.persist()` exempts origin (if granted)
- Home-screen PWAs exempt
- Neither helps on `file://`

**Consequence**: Weekly players safe; "play for a month, come back next season" players lose saves. Empty-state copy must be honest.

### 3. Host/domain change = total loss (VERIFIED)

localStorage/IndexedDB keyed by origin. New host = new origin = empty storage. No transfer mechanism.

**Consequence**: Deployed URL = permanent infrastructure. Host move needs migration story or explicit "saves don't transfer" notice.

### 4. Quota (VERIFIED)

~5 MB per origin across Chrome/Edge/Firefox/Safari (5-10 MB range). `QuotaExceededError` on overflow. `navigator.storage.estimate()` is runtime check.

### Summary for Z.ai Phase 0 (VERIFIED)

1. Ship on `https`; `file://` = `unavailable` with honest UI
2. Request `navigator.storage.persist()` at startup
3. Safari 7-day eviction real: weekly safe, returning-after-months loses saves
4. Treat deployed URL as permanent; host move strands saves
