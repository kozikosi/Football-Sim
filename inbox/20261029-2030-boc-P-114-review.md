## New findings (beyond reviews #1/#2)

### F1 — `seasonState.playerStats[user]` is undefined (real bug)
`playerStats` is keyed by `team|name` (accumulatePlayerStats, l.3464). `Object.values(seasonState.playerStats[user]||{})` always yields `[]`. Top-players card would be empty. Fix: `Object.values(seasonState.playerStats).filter(r=>r.team===user)`.

### F2 — `formatPlayerStats` does not exist
UK references it in the player card. Pre-Colors has `seasonStatLine(group, st)` (l.3632). Use that.

### F3 — `renderSeasonSummaryPanel` returns a string but is called as a void renderer
UK's integration calls `renderSeasonSummaryPanel(container)` and then `document.getElementById('continueToReviewBtn')?.addEventListener(...)`. If the function returns HTML without setting `container.innerHTML`, the button never exists and wiring silently no-ops. Fix: set `container.innerHTML = renderSeasonSummaryPanel()` then wire.

### F4 — `getTeamColor`/`zpbTeamLogo` unguarded
Used in 6+ spots. Guard with `typeof === 'function'` and fall back to `var(--gold)` / `TEAM_ABBR`. (VL caught; re-stating because UK's improved text must carry the guard.)

### F5 — Undefined keyframes/classes
`textShimmer`, `buttonShimmer`, `championRotate`, `badgePulse`, and the `.foil-shimmer` class are referenced but absent (P-007/P-101/P-111/P-183 territory). Either add minimal keyframes here or document the dependency. I recommend adding minimal keyframes in this change (cheap) and noting the full shimmer lands with P-111/P-183.

### F6 — Undefined CSS variables
`--rose`, `--gold-light`, `--team-primary`/`--team-secondary`/`--accent` are referenced. `--accent`/`--accent2` exist; `--rose`/`--gold-light`/`--team-*` do not. Guard with fallbacks.

### F7 — Palette literals (Beam caught)
`#fff` (playoffs badge text), `#fff8e1` (near-white), `rgba(255,255,255,0.4)` (white shimmer). Replace with `var(--text)`, `var(--gold)` (or a rose tint), and `rgba(212,175,55,0.3)`.

### F8 — `showSummary` flag lifecycle
Not initialised in `startSeason` (l.3457 area) and not reset. `simRestOfSeason` sets it true. Need to reset to false in `startSeason` and on "Continue to Review". Also, `renderSeasonTab` is called from many sites; if `showSummary` stays true after navigation, the summary persists. Reset on continue is enough, but also reset when starting a new season.

### F9 — `awardsRS` MVP/opoy/dpoy/coach may be null in edge cases
UK's `userAwards.find(...)` assumes existence. In practice MVP always computed. But guard with optional chaining to avoid a thrown error breaking the whole panel.

### F10 — `seasonState.champion` is undefined during the summary (correct)
`simRestOfSeason` stops at `regularReview`, so `champion` is undefined and the champ confetti never shows. That's correct — the summary celebrates the regular season. UK's `wonSuperBowl` check is dead code here but harmless. Leave it (it's forward-compatible if the summary is ever reused post-playoffs).

### F11 — `divRank` uses 1-based index; if user not found returns 0
`divisionStandings(...).findIndex(...) + 1` → 0 when not found (−1+1). Guard: `|| '—'`.

### F12 — Button primary text when `myGame` is null
UK assumes `myGame` exists. In this sim every team plays every week (no byes), so it exists, but guard with `myGame ? ... : 'Play'`.

### F13 — `renderSeasonTab` wrapper must not skip `add100Button`/rewards/stepper
UK's proposed `renderSeasonTab` calls `renderSeasonSummaryPanel` and returns, skipping `add100Button`, `checkRewards`, `updateStepper`. The wrapper must still call those. Fix in integration.

### D. `renderSeasonSummaryPanel()` (new) — corrected

```javascript
function renderSeasonSummaryPanel(){
  const user = seasonUserTeam();
  const st = computeStandings(seasonState.schedule, teamNames());
  const s = st[user];
  const conf = conferenceOfTeam(user);
  const seed = (seasonState.seeds && seasonState.seeds[conf]) ? seasonState.seeds[conf].find(x=>x.team===user) : null;
  const isOneSeed = !!(seed && seed.seed === 1);
  const madePlayoffs = !!seed;
  const champion = seasonState.champion;
  const wonSuperBowl = champion === user;
  const pf = s.pf, pa = s.pa, pd = pf - pa;
  const record = `${s.wins}-${s.losses}${s.ties ? '-'+s.ties : ''}`;
  const divRows = divisionStandings(conf, st, seasonState.schedule); // note: divisionStandings takes division name, not conf
  // correct call: divisionStandings(divisionOfTeam(user), st, seasonState.schedule)
  const divRank = (divisionStandings(divisionOfTeam(user), st, seasonState.schedule).findIndex(d=>d.team===user) + 1) || '—';

  const awards = seasonState.awardsRS || {individual:[]};
  const userAwards = awards.individual.filter(a => (a.c && a.c.team===user) || a.team===user);
  const mvp  = userAwards.find(a => a.title && a.title.startsWith('Most'));
  const opoy = userAwards.find(a => a.title && a.title.startsWith('Offensive'));
  const dpoy = userAwards.find(a => a.title && a.title.startsWith('Defensive'));
  const coach = userAwards.find(a => a.title && a.title.startsWith('Coach'));

  const colorOf = (t) => (typeof getTeamColor === 'function') ? getTeamColor(t) : 'var(--gold)';
  const logoOf  = (t) => (typeof zpbTeamLogo === 'function') ? zpbTeamLogo(t) : (TEAM_ABBR[t] || t.slice(0,3).toUpperCase());
  const userColor = colorOf(user);

  const badges = [];
  badges.push(`<span class="summary-badge record">${record}</span>`);
  badges.push(`<span class="summary-badge pf">${pf} PF</span>`);
  badges.push(`<span class="summary-badge pa">${pa} PA</span>`);
  badges.push(`<span class="summary-badge pd ${pd>=0?'pos':'neg'}">${pd>=0?'+':''}${pd} PD</span>`);
  if(seed) badges.push(`<span class="summary-badge seed">#${seed.seed} Seed</span>`);
  badges.push(`<span class="summary-badge div">Div #${divRank}</span>`);
  if(madePlayoffs) badges.push(`<span class="summary-badge playoffs">PLAYOFFS</span>`);
  if(isOneSeed) badges.push(`<span class="summary-badge one-seed shimmer">#1 SEED</span>`);
  if(wonSuperBowl) badges.push(`<span class="summary-badge champ shimmer">CHAMPIONS</span>`);

  // top 3 players by composite impact
  const topPlayers = Object.values(seasonState.playerStats)
    .filter(r => r.team === user)
    .sort((a,b) => ((b.st.passYds||0)+(b.st.rushYds||0)*1.4+(b.st.recYds||0)+(b.st.sack||0)*40+(b.st.tkl||0)*4)
                  - ((a.st.passYds||0)+(a.st.rushYds||0)*1.4+(a.st.recYds||0)+(a.st.sack||0)*40+(a.st.tkl||0)*4))
    .slice(0,3);

  const playerCards = topPlayers.map(p=>`
    <div class="summary-player-card">
      <div class="spc-avatar" style="background:${userColor}">${(p.name||'?').charAt(0)}</div>
      <div class="spc-info">
        <div class="spc-name ${p.ovr>=90?'shimmer':''}">${p.name}</div>
        <div class="spc-meta">${p.group} · ${p.ovr} OVR</div>
        <div class="spc-stats">${seasonStatLine(p.group, p.st)}</div>
      </div>
    </div>`).join('');

  const confetti = (wonSuperBowl || isOneSeed) ? '<div class="summary-confetti"></div>' : '';
  const champBanner = wonSuperBowl ? `<div class="summary-champ-banner"><span class="foil-shimmer gold">CHAMPIONS</span></div>` : '';
  const oneSeedBanner = isOneSeed ? `<div class="summary-one-seed-banner"><span class="foil-shimmer gold">#1 SEED</span></div>` : '';

  const mvpName = mvp && mvp.c ? mvp.c.name : (mvp && mvp.team ? mvp.team : '');

  return `
    <div class="panel summary-panel">
      ${confetti}${champBanner}${oneSeedBanner}
      <div class="summary-header">
        <div class="summary-team" style="--team-primary:${userColor};">
          <div class="summary-logo">${logoOf(user)}</div>
          <div class="summary-name">${user}</div>
        </div>
        <div class="summary-record">${record}</div>
      </div>
      <div class="summary-badges">${badges.join('')}</div>
      <div class="summary-stats">
        <div class="summary-stat"><span class="summary-stat-val">${pf}</span><span class="summary-stat-lbl">POINTS FOR</span></div>
        <div class="summary-stat"><span class="summary-stat-val">${pa}</span><span class="summary-stat-lbl">POINTS AGAINST</span></div>
        <div class="summary-stat"><span class="summary-stat-val ${pd>=0?'pos':'neg'}">${pd>=0?'+':''}${pd}</span><span class="summary-stat-lbl">POINT DIFF</span></div>
        <div class="summary-stat"><span class="summary-stat-val">${mvpName}</span><span class="summary-stat-lbl">MVP</span></div>
      </div>
      <div class="summary-players">
        <h4>SEASON STARS</h4>
        <div class="summary-player-row">${playerCards || '<span class="narr">No player stats yet.</span>'}</div>
      </div>
      <div class="summary-actions">
        <button class="resetbtn zpb-continue" id="continueToReviewBtn">Continue to Review</button>
      </div>
    </div>`;
}
```
