**Drive model usage:**
- `simulateKickoff()` → returns starting yardline (uses `krYdsPerRet`, `krPerGame`, `tbRate`)
- `simulatePunt()` → returns net yards, field position (uses `netPuntAvg`, `in20Rate`, `tbRate`)
- `simulatePuntReturn()` → returns return yards (uses `prYdsPerRet`)
- Field position feeds into `simulateDrive(startYardline, ...)`

**Kicker/Punter ratings adjustment:**
- Kicker `KO` rating → affects touchback rate (higher KO = more TBs)
- Punter `P` rating → affects gross/net avg, In20%
- Returner rating → affects `krYdsPerRet`, `prYdsPerRet`
