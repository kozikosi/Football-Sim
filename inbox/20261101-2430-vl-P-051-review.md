### Edge cases
- **Empty/null names**: Some roster slots have `name: null` (e.g., `"DE1":{"ovr":78,"name":"Boye Mafe"}` is filled, but many have `name: null`). The truncation logic must handle null names gracefully — skip truncation if name is null or empty.
- **Single-name players**: Players with single-word names (e.g., "Mahomes") should not be truncated — the last name equals the full name.
- **Multi-part last names**: Players like "Dexter Lawrence II" — last name extraction should take everything after the first space.
- **Resize listener**: Must be debounced to avoid excessive re-renders during resize.
- **390px check**: At 390px, names should show last name only; at 1280px, full names should show.
