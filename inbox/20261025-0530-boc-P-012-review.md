1. **Missing state update on edit.** `updateWeightBtnStates()` is only called in the two button handlers. The number-input handler (l.550 region) calls `render()` on edit but not `updateWeightBtnStates()`, so editing a weight does NOT flip "My Weights" to active as the behaviour table requires. Fix: call `updateWeightBtnStates()` in the input handler too, and on init after `buildControls()`/`render()`.

2. **Badges aggregation is unspecified.** Badges (`Can't Run`/`Weak D`/`Can't Pass`) are computed per team inside the `scored.forEach` loop (l.624-627) and currently inline in that row (l.631). Moving them to a single `#synergyBadges` container below the table loses the team association: the container would show only the last team's badges (or require collecting all teams' badges, which duplicates). Recommend keeping badges per-team but on a second line inside the cell, OR (if a single container is wanted) showing only the user's selected team's badges with a label. The work item must pick one; the Architect should not have to guess. I recommend per-team second line (smallest change, no info loss).

3. **Dead class toggle.** `classList.toggle('active', …)` does nothing: there is no `.resetbtn.active` CSS rule (only `.tabbtn.active` and `.footlink.active`). Harmless but dead. Either add a CSS rule or drop the toggle and rely on inline styles. Recommend dropping the toggle to avoid confusion, OR adding `.resetbtn.active` to the theme. Since inline styles already set bg/color, drop the toggle.

4. **Inline styles override the theme gradient.** `.resetbtn` has a gold gradient in this theme (l.247). Setting `background: var(--accent)` / `var(--panel2)` replaces the gradient with flat fills. Minor visual inconsistency. Acceptable if intended, but should be noted. Alternative: toggle a class that swaps gradient vs flat. I leave the flat approach but flag it.

5. **Button label change verified.** Old labels "Use model weights"/"Back to my weights" → "Default"/"My Weights" match l.548. Good.

6. **Explanatory text change verified.** Old l.547 matches. New text is clearer. Good.
