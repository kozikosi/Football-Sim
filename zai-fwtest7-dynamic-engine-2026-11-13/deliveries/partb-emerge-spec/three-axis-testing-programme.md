## The discipline

Run the fixed-vs-fluctuating test **per context axis** through the two-gap Lab machinery (gaps 10 and 20, report R first, frozen θ in provenance — the settled council protocol). **No new axis is authored until the first three earn or fail the method** (GLM's rule, adopted verbatim in PD.1). Each axis: partial pooling of the slice toward the global λ̂ (shrinkage, never hand-set), fitted on 2016–22, validated on the frozen 2023–25 holdout.

## What each axis settles

- (a): whether the engine should carry the **two-regime split** (regulated/chaotic) — the D.8 margin evidence says the regime cells differ on HFA and margin shape; the Lab run decides whether λ̂ differs too, or whether the regime difference lives entirely in the drive/margin layer.
- (b): whether rivalry context earns a slot-value multiplier — the upset-rate half already came back inside the band; the prior is now that λ̂ will too (an honest cheap test).
- (c): whether personnel context (the Owner's "key players" verbatim) moves the dial — the first axis that tests the PERSONNEL concept directly.

## The acceptance rule (one rule, all axes)

λ(context) wins iff: held-out **wrong-strict-pairs improve** (23-vs-305 discriminant, quoted by name) + **exact tiers preserved** + bootstrap CI on the improvement **excludes 0** + mae quoted **with its units caveat**. Inside the bands ⇒ **fixed wins on parsimony; the axis is recorded dead** — a result, not a failure. (Worked example: D.8 cut 2.)

## The standing checks every Lab bench run must report alongside

1. **Between-team SD equality** — between-team SD of season-mean points must equal the λ budget (P-347; three seats converged); any bench fix reports it with the (N=1000) batch comparison.
2. **Snapshot consistency** — the fluctuating arm reads only the frozen `contextSnapshot`; `hash(save, week) → hash(contextSnapshot)` round-trip in CI the day the snapshot ships (the module sketch ships the hash).
3. **The premium-destination monitor** — the 11 flip rows watched at WR1 ×2, DT1, SS/FS, TE1, RB1, OG1 (where the wrong tier costs a real pick), not at the exotic source slots; the module sketch ships the monitor hook.

## The two-regime candidate (Part B §7 — proposed only if (a) lands or argued from the same receipts)

Regulated/predictable (REG, non-rivalry) vs chaotic (playoffs + rivalry + one-score stakes), context-selected, never user-togglable, each calibrated on its own 2016–25 cells. **My amendment from the executed evidence:** the first regime pair to calibrate is **HFA + margin-noise σ** (both separated cleanly by season type in the D.8 cut), not λ — the regime frame earns its keep on the cells that already separated, while every λ-axis λ̂ to date sits inside its bands.

## What is deliberately NOT in the programme

- No authoring of new axes by taste (the Owner's list is a queue, not a menu).
- No fitting on the holdout (frozen 2023–25; tuning on the holdout is the named sin).
- No display-layer effects (fit layer only until the Owner rules otherwise — PD.1's open question).
- No proxy covariates (unmeasured context is dropped with a label).
