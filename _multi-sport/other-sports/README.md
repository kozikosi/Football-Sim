# Other Sports

**Status:** planning
**Priority:** 5 (after NBA all-time)

## Overview

Simulations for MLB, NHL, MLS, and top football leagues (Premier League, La Liga, Bundesliga, Serie A, Ligue 1, etc.). Following the same engine template as the NFL and NBA sims.

## Candidate sports

| Sport | League | Teams | Schedule | Playoffs |
|-------|--------|-------|----------|----------|
| Baseball | MLB | 30 | 162 games | 12-team bracket |
| Hockey | NHL | 32 | 82 games | 16-team bracket |
| Soccer | MLS | 29 | 34 games | 18-team bracket |
| Soccer | Premier League | 20 | 38 games | none (table) |
| Soccer | La Liga | 20 | 38 games | none (table) |
| Soccer | Bundesliga | 18 | 34 games | none (table) |
| Soccer | Serie A | 20 | 38 games | none (table) |
| Soccer | Ligue 1 | 18 | 34 games | none (table) |

## Key challenges

1. **Football leagues have no playoffs** — the season is a round-robin table. The engine needs a different playoff/standings model.
2. **MLB has no draft in the same sense** — the season is 162 games with a completely different stat set.
3. **NHL has a different playoff format** — 16-team bracket, best-of-7.
4. **Player ratings** — FIFA ratings for football, custom for others. Collective creation needed for all-time.
