# NBA All-Time Sim

**Status:** planning
**Priority:** 4 (after NBA current)
**Owner:** the user (permissions, publishing, roster, conceptual direction, era adjustments)
**Architect:** Claude (technical authority)

## Overview

An all-time NBA draft/season simulation featuring ~1,200 of the best all-time NBA players. Same engine as NBA current, but with all-time player pool and era adjustments.

## Data needed

- ~1,200 players (all-time greats + current players with era adjustment)
- 30 teams (all-time rosters)
- Position weights (same as NBA current, or adjusted for era)
- Flex rules (same as NBA current, or adjusted for era)

## Key challenges

1. **Era adjustment** — how to rate players from the 1960s vs 2020s?
2. **Team assignment** — primary team for all-time greats?
3. **Position flexibility** — same as current NBA, or adjusted for era?
4. **Draft format** — same as NBA current, or different?

## Math

Same engine as NBA current (NBA math), but with all-time player pool and era adjustments.
