HieroGlyphic v1

A cleaner architecture for NFL Draft Simulator

🎯 Design Philosophy

  • Clean separation of concerns
  • Engine remains pure (no DOM)
  • Learn from w37/w38 beauty, fix bugs
  • Future-ready for React/Svelte
  • Preserve all game mechanics

⚡ Engine (from Colors)

  • Seeded RNG (deterministic)
  • Optimal lineup solver (Hungarian)
  • Flex penalty system
  • Drive generator (P-205)
  • Realistic kicking curves (P-204)
  • Overtime rules (P-206)

✨ UI Inspiration

  • Rose-gold aesthetic from w37/w38
  • Cinzel Decorative typography
  • Shimmer effects for elites (90+)
  • Team-colored elements
  • Clean, polished components
  • Better than Pre-Colors

Architecture

UI Layer (Components)
↓
State Management
↓
Game Logic / Orchestration
↓
Pure Engine (Colors-based)

Key Improvements

Modular Design

Clear separation between engine, UI, and state for easier testing and maintenance

Type Safety Ready

Structure designed for easy TypeScript migration

Framework Agnostic

Can migrate to React or Svelte with minimal engine changes

Fixed w37/w38 Bugs

Learning from their issues while keeping the beauty

Performance Focused

Optimized rendering, memoization where needed

Engine Purity

All game logic is pure and deterministic with seeded RNG
