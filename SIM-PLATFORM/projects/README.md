# projects/ — the four priority projects

One folder per project, in the Owner's priority order. Each folder holds the *human* work: the
scope, the data schema, the task list, and the receipts. The code lands in the platform folders
(`engine/`, `packs/`, `data/`) once the Architect implements it.

| # | project | status | what it needs first |
|---|---|---|---|
| 1 | [`1-football-current/`](1-football-current/) | protected — the reference build | nothing; it is the inheritance |
| 2 | [`2-football-all-time/`](2-football-all-time/) | open | the Owner's era-mode answers, then ratings |
| 3 | [`3-nba-current/`](3-nba-current/) | open | the Owner's flex/draft answers, the NBA2K mapping |
| 4 | [`4-nba-all-time/`](4-nba-all-time/) | open | the same era-mode answers, then the pool |

**Claim a slice before you start** — the board is [`../OWNERSHIP.md`](../OWNERSHIP.md). A project
folder is *documentation of intent*; the live work is always in somebody's lane until the Architect
merges it.
