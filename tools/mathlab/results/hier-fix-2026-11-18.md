Reading: failed 4th-down tries now end the drive (about a quarter of failed tries used to survive: 26% of failed passes, 25% of failed runs). Conversion rates are untouched, so the fix removes only the artefact. The cost is 0.28 points a game (0.6%) and 0.1 more drives a game. **I did not re-run the totals bar against real seasons; that is a REPORT I owe before anyone calls the fix "good for totals"** (points moved the right way on a sim that already ran slightly hot, but that is inferred).

## 3. What this changes downstream

- `Pools.recDown` is gone: one hierarchy, `Pools.rec` (5 levels), used by the pools node and the class sampler. `recDownKeys` removed.
- The default pools node changed, so the replay pin in `pools-game.test.ts` moved (pack hash unchanged, log hash and score moved; deliberate, re-pinned).
- `yards-given-class-2026-11-18.md` and `glm-pass-class-2026-11-17.md` measured the pool baseline on the OLD `rec` for the class mix (`passclass.py pool_class_probs`). That baseline is now down-preserving, so those GLM-vs-pool numbers are **stale until re-run**. The lambda-axis Lab re-runs them as its first step.
- `tools/glm-shift.ts` now reads `P.rec` where it read `P.recDown` (same hierarchy as before for the control arm).
